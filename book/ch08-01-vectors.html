The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

값의 목록을 벡터로 저장

우리가 살펴볼 첫 번째 컬렉션 유형은 벡터라고도하는 Vec<T>입니다. 벡터를 사용하면 모든 값을 메모리에서 서로 옆에 두는 단일 데이터 구조에 하나 이상의 값을 저장할 수 있습니다. 벡터는 동일한 유형의 값 만 저장할 수 있습니다. 파일의 텍스트 줄이나 장바구니의 항목 가격과 같은 항목 목록이있을 때 유용합니다.

열거형을 사용하여 여러 형식 저장Using an enum to store multiple types

벡터는 같은 타입의 값만 저장할 수 있습니다. 이것은 불편할 수 있습니다. 다른 타입의 항목 목록을 저장할 필요가 있는 사용 사례가 분명히 있습니다. 다행스럽게도, 열거형의 변형은 같은 열거형으로 정의됩니다. 그래서 다른 타입의 요소를 표현하기 위해 한 타입이 필요할 때, 우리는 열거형을 정의하고 사용할 수 있습니다!

예를 들어, 스프레드시트에 있는 열 중 일부가 정수, 부동 소수점 숫자 및 문자열을 포함하는 행에서 값을 가져오고 싶다고 가정해 보겠습니다. 우리는 다른 값 유형을 가진 변형을 가진 열거형을 정의할 수 있으며, 모든 열거형 변형은 같은 유형으로 간주될 것입니다: 열거형의 유형. 그런 다음, 그 열거형을 보유하는 벡터를 만들 수 있으며, 궁극적으로 다른 유형을 보유할 수 있습니다.

러스트는 컴파일 타임에 힙에 어떤 타입이 들어있을지 알아야 합니다. 힙에 어떤 타입이 허용되는지에 대해서도 명시해야 합니다. 만약 러스트가 어떤 타입이든 hold할 수 있다면, 하나 이상의 타입이 벡터의 엘리먼트에서 수행된 연산으로 에러를 발생시킬 가능성이 있습니다. enum plus a를 사용하면 match expression은 러스트가 컴파일 시간에 모든 가능한 케이스가 처리되도록 보장한다는 것을 의미합니다.

만약 여러분이 프로그램이 런타임에 벡터에 저장하기 위한 타입의 집합을 모른다면, 열거형 기법은 작동하지 않을 것이다. 대신, 18장에서 다룰 트레잇 객체를 사용할 수 있다.

이제 벡터를 사용하는 가장 일반적인 방법 중 일부를 논의 했으므로 반드시 검토하십시오. API 문서 무시 에 정의 된 많은 유용한 방법의 모든 Vec<T> 표준 라이브러리에 의해. 예를 들어, 이외에 push, a pop 메서드는 마지막 요소를 제거하고 반환합니다.
