DST를 사용하기 위해, 러스트는 Sized 트레잇을 제공하여 타입의 사이즈가 컴파일 타임에 알려져 있는지 여부를 결정합니다. 이 트레잇은 컴파일 타임에 사이즈가 알려진 모든 것에 대해 자동으로 구현됩니다. 또한, 러스트는 Sized에 대한 바운드를 모든 제네릭 함수에 암시적으로 추가합니다. 즉, 다음과 같은 제네릭 함수 정의입니다:

fn generic<T>(t: T) {
    // --snip--
}

실제로 우리가 이것을 쓴 것처럼 취급됩니다 :

fn generic<T: Sized>(t: T) {
    // --snip--
}

기본적으로 일반 함수는 컴파일 시간에 알려진 크기를 가진 형식에서만 작동합니다. 그러나 다음 특수 구문을 사용하여 이 제한을 완화할 수 있습니다.

fn generic<T: ?Sized>(t: &T) {
