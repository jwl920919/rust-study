The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

함수

함수는 Rust 코드에서 널리 사용됩니다. 이미 이 언어에서 가장 중요한 함수 중 하나인 main 함수를 확인했습니다. 이 함수는 많은 프로그램의 진입점입니다. 또한 새로운 함수를 선언할 수 있게 해주는 fn 키워드도 확인했습니다.

Rust 코드에서는 함수와 변수 이름에 대해 snake case를 관용적 스타일로 사용합니다. 이 스타일에서는 모든 글자가 소문자이며 밑줄(_)로 단어를 구분합니다. 예제 함수 정의를 포함하는 프로그램은 다음과 같습니다:

파일 이름: src/main.rs

fn main() {
    println!("Hello, world!");

    another_function();
}

fn another_function() {
    println!("Another function.");
}

Rust에서 함수를 정의하려면 fn 뒤에 함수 이름과 괄호를 입력합니다. 중괄호는 함수 본문이 시작되고 끝나는 위치를 컴파일러에게 알려줍니다.

우리가 정의한 함수를 호출할 수 있습니다. 이름 뒤에 괄호를 입력하면 됩니다. 왜냐하면 another_function 프로그램 내에서 정의되며, 내부에서 호출될 수 있습니다. main 함수. 우리가 정의한 것을 주목하라. another_function 이후 오시는 길 main 소스 코드에서 함수를 정의할 수도 있습니다. 러스트는 여러분이 함수를 정의할 때 상관하지 않습니다. 단지 함수는 호출자가 볼 수 있는 범위의 어딘가에 정의되어 있을 뿐입니다.

함수를 더 자세히 살펴보기 위해 functions라는 이름의 새로운 바이너리 프로젝트를 시작해 봅시다. another_function 예제를 src/main.rs에 넣고 실행하십시오. 다음 출력을 볼 수 있습니다.

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.28s
     Running `target/debug/functions`
Hello, world!
Another function.

main 함수에 나타나는 순서대로 각 줄이 실행됩니다. 먼저 "Hello, world!" 메시지가 출력되고, another_function이 호출되어 그 메시지가 출력됩니다.

매개변수

함수는 매개변수를 가질 수 있습니다. 매개변수는 함수 시그니처의 일부인 특별한 변수입니다. 함수에 매개변수가 있으면, 함수를 호출할 때 해당 매개변수에 구체적인 값을 전달할 수 있습니다. 기술적으로 구체적인 값은 인수(argument)라고 부르지만, 일상적인 대화에서는 함수 정의에 있는 변수나 함수 호출 시 전달되는 구체적인 값을 가리킬 때 매개변수와 인수를 혼용하는 경우가 많습니다.

이 버전의 another_function에서는 매개변수를 추가합니다.

파일 이름: src/main.rs

fn main() {
    another_function(5);
}

fn another_function(x: i32) {
    println!("The value of x is: {x}");
}

이 프로그램을 실행해 보세요. 다음과 같은 출력이 표시됩니다.

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 1.21s
     Running `target/debug/functions`
The value of x is: 5

another_function의 선언에는 x이라는 이름의 매개변수가 하나 있습니다. x의 타입은 i32로 지정되어 있습니다. 5에 another_function를 전달하면, println! 매크로는 형식 문자열에서 5가 있던 중괄호 위치에 x를 배치합니다.

함수 시그니처에서는 각 매개변수의 타입을 선언해야 합니다. 이는 Rust 설계에서 의도적으로 내린 결정입니다. 함수 정의에서 타입 주석을 요구하면, 컴파일러가 코드의 다른 곳에서 타입을 추론하기 위해 사용자가 타입을 명시적으로 지정할 필요가 거의 없습니다. 또한 컴파일러가 함수가 기대하는 타입을 알면 더 유용한 에러 메시지를 제공할 수 있습니다.

여러 매개변수를 정의할 때는 다음과 같이 쉼표로 구분합니다.

파일 이름: src/main.rs

fn main() {
    print_labeled_measurement(5, 'h');
}

fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}

이 예제에서는 두 개의 매개변수를 가진 print_labeled_measurement라는 이름의 함수를 만듭니다. 첫 번째 매개변수는 value이며 타입은 i32입니다. 두 번째 매개변수는 unit_label이며 타입은 char입니다. 이 함수는 value와 unit_label를 모두 포함하는 텍스트를 출력합니다.

이 코드를 실행해 보겠습니다. 현재 functions 프로젝트의 src/main.rs 파일에 있는 프로그램을 앞선 예제로 교체하고 cargo run을 사용하여 실행하세요:

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/functions`
The measurement is: 5h

5의 값으로 value, 'h'의 값으로 unit_label를 사용하여 함수를 호출했기 때문에 프로그램 출력에는 해당 값들이 포함되어 있습니다.

문장과 표현식

함수 본문은 일련의 문장으로 구성되며, 선택적으로 표현식으로 끝날 수 있습니다. 지금까지 살펴본 함수들은 끝부분에 표현식을 포함하지 않았지만, 문장의 일부로 표현식을 사용한 적은 있습니다. Rust는 표현식 기반 언어이므로, 이 차이를 이해하는 것이 중요합니다. 다른 언어에는 이러한 구분이 없으므로, 문장과 표현식이 무엇인지 그리고 그 차이가 함수 본문에 어떤 영향을 미치는지 살펴 보겠습니다.

  • 문장은 특정 작업을 수행하지만 값을 반환하지 않는 지시문입니다.
  • 표현식은 결과 값으로 평가됩니다.

몇 가지 예를 살펴보겠습니다.

실제로 이미 문(statement)과 표현식(expression)을 사용했습니다. 변수를 만들고 let 키워드로 값을 할당하는 것은 문입니다. Listing 3-1에서 let y = 6;는 문입니다.

함수 정의도 문입니다. 앞의 예제 전체는 그 자체로 하나의 문입니다. (곧 살펴보겠지만, 함수를 호출하는 것은 문이 아닙니다.)

문은 값을 반환하지 않습니다. 따라서 다음 코드가 시도하듯 let 문을 다른 변수에 할당할 수 없습니다. 이렇게 하면 오류가 발생합니다:

파일 이름: src/main.rs

fn main() {
    let x = (let y = 6);
}

이 프로그램을 실행하면 다음과 같은 오류가 발생합니다:

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
error: expected expression, found `let` statement
 --> src/main.rs:2:14
  |
2 |     let x = (let y = 6);
  |              ^^^
  |
  = note: only supported directly in conditions of `if` and `while` expressions

warning: unnecessary parentheses around assigned value
 --> src/main.rs:2:13
  |
2 |     let x = (let y = 6);
  |             ^         ^
  |
  = note: `#[warn(unused_parens)]` (part of `#[warn(unused)]`) on by default
help: remove these parentheses
  |
2 -     let x = (let y = 6);

warning: `functions` (bin "functions") generated 1 warning
error: could not compile `functions` (bin "functions") due to 1 previous error; 1 warning emitted

let y = 6 문은 값을 반환하지 않으므로, x에 바인딩할 대상이 없습니다. 이는 C나 Ruby와 같은 다른 언어에서 발생하는 상황과 다릅니다. 이러한 언어에서는 할당이 할당된 값을 반환하므로, x = y = 6처럼 작성하여 x와 y 모두에 값 6를 할당할 수 있습니다. 그러나 Rust에서는 그렇지 않습니다.

표현식은 값을 산출하며, Rust에서 작성하는 나머지 코드의 대부분을 차지합니다. 예를 들어 5 + 6과 같은 수학 연산은 11이라는 값으로 평가되는 표현식입니다. 표현식은 문(statement)의 일부가 될 수도 있습니다. Listing 3-1에서 6 문장의 let y = 6;은 6이라는 값으로 평가되는 표현식입니다. 함수 호출은 표현식입니다. 매크로 호출도 표현식입니다. 중괄호로 생성되는 새로운 스코프 블록도 표현식입니다.

파일 이름: src/main.rs

fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("The value of y is: {y}");
}

이 표현식은

{
    let x = 3;
    x + 1
}

이 경우 4로 평가되는 블록입니다. 이 값은 y 문에서 let에 바인딩됩니다. x + 1 줄 끝에 세미콜론이 없는데, 이는 지금까지 본 대부분의 줄과 다릅니다. 식은 세미콜론으로 끝나지 않습니다. 식 끝에 세미콜론을 추가하면 식이 문장이 되며, 이때는 값을 반환하지 않습니다. 다음으로 함수의 반환 값과 식을 살펴볼 때 이 점을 염두에 두세요.

반환 값이 있는 함수

함수는 호출한 코드에 값을 반환할 수 있습니다. 반환 값에는 이름을 붙이지 않지만, 화살표(->) 뒤에 타입을 선언해야 합니다. Rust에서 함수의 반환 값은 함수 본문 블록의 마지막 표현식 값과 동일합니다. return 키워드를 사용해 값을 지정하고 함수에서 조기에 반환할 수 있지만, 대부분의 함수는 마지막 표현식을 암시적으로 반환합니다. 값을 반환하는 함수의 예시는 다음과 같습니다.

파일 이름: src/main.rs

fn five() -> i32 {
    5
}

fn main() {
    let x = five();

    println!("The value of x is: {x}");
}

함수 호출, 매크로 또는 심지어 let 본문에서 In the five 기능 - 단지 숫자 5 그 자체로. 이것은 러스트에서 완벽하게 유효한 함수입니다. 함수의 반환 타입도 다음과 같이 지정됩니다. -> i32. 이 코드를 실행해보세요; 출력은 다음과 같아야 합니다:

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.30s
     Running `target/debug/functions`
The value of x is: 5

five의 5은 함수의 반환 값입니다. 그래서 반환 타입이 i32입니다. 이를 자세히 살펴보겠습니다. 중요한 부분이 두 가지 있습니다. 첫째, let x = five(); 줄은 함수의 반환 값을 사용해 변수를 초기화하고 있음을 보여줍니다. 함수 five가 5를 반환하므로, 해당 줄은 다음과 같습니다:

#![allow(unused)]
fn main() {
let x = 5;
}

둘째, five 함수에는 매개변수가 없으며 반환 값의 타입을 정의합니다. 함수 본문은 값을 반환하려는 식이므로 세미콜론이 없는 5입니다.

다른 예를 살펴보겠습니다.

파일 이름: src/main.rs

fn main() {
    let x = plus_one(5);

    println!("The value of x is: {x}");
}

fn plus_one(x: i32) -> i32 {
    x + 1
}

이 코드를 실행하면 The value of x is: 6이 출력됩니다. 그런데 x + 1이 포함된 줄의 끝에 세미콜론을 붙여 식을 문으로 변경하면 어떻게 될까요?

파일 이름: src/main.rs

fn main() {
    let x = plus_one(5);

    println!("The value of x is: {x}");
}

fn plus_one(x: i32) -> i32 {
    x + 1;
}

이 코드를 컴파일하면 다음과 같은 오류가 발생합니다.

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
error[E0308]: mismatched types
 --> src/main.rs:7:24
  |
7 | fn plus_one(x: i32) -> i32 {
  |    --------            ^^^ expected `i32`, found `()`
  |    |
  |    implicitly returns `()` as its body has no tail or `return` expression
8 |     x + 1;
  |          - help: remove this semicolon to return this value

For more information about this error, try `rustc --explain E0308`.
error: could not compile `functions` (bin "functions") due to 1 previous error

주 오류 메시지인 mismatched types이 이 코드의 핵심 문제를 드러냅니다. 함수 plus_one의 정의는 i32를 반환한다고 명시하지만, 문(statement)은 값으로 평가되지 않습니다. 이는 단위 타입인 ()로 표현됩니다. 따라서 아무것도 반환되지 않아 함수 정의와 모순이 발생하고, 이로 인해 오류가 발생합니다. 이 출력에서 Rust는 이 문제를 해결하는 데 도움이 될 수 있는 메시지를 제공합니다. 세미콜론을 제거하라고 제안하며, 이렇게 하면 오류가 수정됩니다.
