이 관용구의 예외는 같은 이름을 가진 두 개의 항목을 use 문 범위로 가져오는 경우입니다. 러스트는 이를 허용하지 않기 때문입니다. Listing 7-15는 두 개의 Result 유형을 같은 이름을 가지지만 다른 부모 모듈이 있는 범위로 가져오는 방법과 이들을 참조하는 방법을 보여줍니다.

보시다시피, 부모 모듈을 사용하면 두 개의 Result 타입을 구분할 수 있습니다. 대신 use std::fmt::Result와 use std::io::Result를 지정한다면, 같은 범위에 두 개의 Result 타입을 가질 것이고, 러스트는 Result를 사용할 때 어떤 것을 의미하는지 알지 못할 것입니다.

외부 패키지 사용

2 장에서는 임의의 숫자를 얻기 위해 rand라는 외부 패키지를 사용하는 추측 게임 프로젝트를 프로그래밍했습니다. 우리 프로젝트에서 rand를 사용하려면 Cargo.toml에이 줄을 추가했습니다.

rand를 Cargo.toml에 종속성으로 추가하면 Cargo는 rand 패키지 및 크레이트.io의 종속성을 다운로드하고 rand를 프로젝트에 사용할 수 있습니다.

그래서, Bring rand 우리의 패키지의 범위에 정의, 우리는 추가 use 크레이트의 이름으로 시작하는 선, rand, 그리고 우리가 범위로 가지고 가고 싶었던 품목을 목록으로 만들었습니다. 그것을 안으로 되새기십시오 “무작위 숫자 를 만들어 내는 일” 무시 제 2 장에서, 우리는에 항목을 가져 rand::prelude module을 호출하고, rand::rng 기능:

use std::io;

use rand::prelude::*;

fn main() {
    println!("Guess the number!");

    let secret_number = rand::rng().random_range(1..=100);

    println!("The secret number is: {secret_number}");

    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    println!("You guessed: {guess}");
}

러스트 커뮤니티의 회원들은 크레이트.io에서 많은 패키지를 사용할 수 있도록 했으며, 패키지에 패키지를 가져오는 것은 동일한 단계를 포함합니다: 패키지의 Cargo.toml 파일에 패키지를 나열하고 use를 사용하여 상자의 항목을 범위로 가져옵니다.

상기 기준은 The standard std 라이브러리는 또한 패키지 외부의 크레이트입니다. 표준 라이브러리는 러스트 언어와 함께 제공되므로 변경할 필요가 없습니다. 카고.toml 포함하다 std. 그러나 우리는 그것을 참조 할 필요가 use 우리의 패키지의 범위에 거기에서 항목을 가지고. 예를 들면, HashMap 우리는이 라인을 사용합니다 :

이것은 표준 라이브러리 크레이트의 이름인 std로 시작하는 절대 경로입니다.

Glob 연산자로 항목 가져오기

이 use 문은 std::collections에 정의 된 모든 공개 항목을 현재 범위에 가져옵니다. glob 연산자를 사용할 때는주의하십시오! Glob은 범위에 어떤 이름이 있는지, 프로그램에서 사용 된 이름이 정의 된 위치를 말하기 어렵게 만들 수 있습니다. 또한 종속성이 정의를 변경하면 가져온 내용이 변경되므로 종속성이 동일한 정의를 추가하면 종속성을 업그레이드 할 때 컴파일러 오류가 발생할 수 있습니다.
