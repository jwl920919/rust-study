러스트 프로그래밍 언어

최신 공식 영문판의 장과 부록을 한국어 HTML로 옮긴 비공식 번역 초안입니다. 로컬에서 읽을 수 있도록 공식 책의 페이지 구성과 예제 코드를 보존했습니다.

책 첫 페이지 열기공식 영문판출처와 라이선스
번역 상태: 전체 장·부록 기계 번역 초안

모든 장과 부록을 최신 원문 기준으로 포함합니다. 번역 문장은 자동 번역 결과이므로 전문 용어와 문장 표현에 오역이 있을 수 있으며, 출판 수준의 교정은 거치지 않았습니다. 코드 예제와 명령어는 원문을 그대로 유지했습니다.

기준 원문: Rust 1.97.0 (2026-07-09) 문서, Rust 2024 Edition.

페이지에서 코드 실행

책의 실행 가능한 Rust 예제 아래 실험실에서 편집을 눌러 코드를 고쳐 실행하거나, 화면 오른쪽 아래 코드 실험실에서 새 코드를 작성할 수 있습니다. 실행에는 인터넷 연결이 필요하며 공식 Rust Playground를 사용합니다.
