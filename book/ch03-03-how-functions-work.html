The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

함수

함수는 러스트 코드에서 널리 사용됩니다. 언어에서 가장 중요한 함수 중 하나 인 main 함수는 많은 프로그램의 진입점입니다. 또한 fn 키워드를 보았으므로 새로운 기능을 선언 할 수 있습니다.

러스트 코드는 모든 글자가 소문자이고 단어가 분리되어 있는 함수와 변수 이름에 대한 일반적인 스타일로 snake case를 사용합니다. 예제 함수 정의를 포함하는 프로그램은 다음과 같습니다:

파일 이름: src/main.rs

fn main() {
    println!("Hello, world!");

    another_function();
}

fn another_function() {
    println!("Another function.");
}

러스트에서 함수를 정의합니다. fn를 입력하고 함수 이름과 괄호를 입력합니다. 중괄호는 함수 본문이 시작되고 끝나는 위치를 컴파일러에게 알려줍니다.

우리가 정의한 함수를 호출할 수 있습니다. 이름 뒤에 괄호를 입력하면 됩니다. 왜냐하면 another_function 프로그램 내에서 정의되며, 내부에서 호출될 수 있습니다. main 함수. 우리가 정의한 것을 주목하라. another_function 이후 오시는 길 main 소스 코드에서 함수를 정의할 수도 있습니다. 러스트는 여러분이 함수를 정의할 때 상관하지 않습니다. 단지 함수는 호출자가 볼 수 있는 범위의 어딘가에 정의되어 있을 뿐입니다.

함수라는 이름의 새로운 바이너리 프로젝트를 시작하여 함수를 더 탐색해 봅시다. another_function 예제를 src/main.rs에 넣고 실행하십시오. 다음 출력을 볼 수 있습니다.

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.28s
     Running `target/debug/functions`
Hello, world!
Another function.

main 함수에 나타나는 순서대로 행이 실행됩니다. 먼저 "Hello, world!"메시지가 인쇄되고 another_function가 호출되고 메시지가 인쇄됩니다.

매개 변수

우리는 함수의 시그니처의 일부인 특별한 변수인 매개변수를 가지기 위해 함수를 정의할 수 있습니다. 함수에 매개변수가 있을 때, 그 매개변수에 대한 구체적인 값을 제공할 수 있습니다. 기술적으로, 구체적인 값은 인수라고 하지만, 일상적인 대화에서 사람들은 함수의 정의에 있는 변수나 함수를 호출할 때 전달되는 구체적인 값에 대해 단어 매개변수와 인수를 번갈아 사용하는 경향이 있습니다.

이 버전의 another_function에서는 매개 변수를 추가합니다.

파일 이름: src/main.rs

fn main() {
    another_function(5);
}

fn another_function(x: i32) {
    println!("The value of x is: {x}");
}

이 프로그램을 실행 해보세요; 당신은 다음과 같은 출력을 얻을 것이다 :

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 1.21s
     Running `target/debug/functions`
The value of x is: 5

의 선언 The Declaration another_function 이름이 있는 매개 변수가 하나 있음 x. 의 종류 x 으로 지정됩니다. i32. 우리가 통과 할 때 5 에 에 another_function, 이 println! 매크로 풋 5 상기 중괄호는 The curly brackets x 문자열 형식입니다.The format string.

함수 서명에서, 각 파라미터의 타입을 선언해야 합니다. 이것은 러스트의 디자인에서 의도적인 결정입니다: 함수 정의에서 타입 주석을 요구하는 것은 컴파일러가 여러분이 의미하는 타입을 알아내기 위해 코드의 다른 곳에서 사용할 필요가 거의 없다는 것을 의미합니다. 컴파일러는 또한 함수가 기대하는 타입을 안다면 더 유용한 에러 메시지를 줄 수 있습니다.

여러 매개변수를 정의할 때, 다음과 같이 매개변수 선언을 쉼표로 구분합니다.

파일 이름: src/main.rs

fn main() {
    print_labeled_measurement(5, 'h');
}

fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}

이 예제에서는 이름이 지정된 함수를 만듭니다.This example created a function named print_labeled_measurement 2개의 매개변수로. 첫번째 매개변수는 지명됩니다 value 그리고 is an i32. 두 번째 이름은 unit_label 및 유형입니다 char. 이 함수는 다음을 모두 포함하는 텍스트를 인쇄합니다. value 그리고 The unit_label.

이 코드를 실행해 봅시다. 현재 프로젝트의 src/main.rs 파일에 있는 프로그램을 이전 예제로 바꾸고 cargo run를 사용하여 실행하세요:

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/functions`
The measurement is: 5h

5를 value와 'h'를 unit_label의 값으로 함수를 호출했기 때문에 프로그램 출력에는 이러한 값이 포함되어 있습니다.

문장과 표현

함수 본문들은 선택적으로 표현식으로 끝나는 일련의 문장들로 구성되어 있습니다. 지금까지 우리가 다루었던 함수들은 엔딩 표현식을 포함하지 않았지만, 여러분은 문장의 일부로 표현식을 보았습니다. 러스트는 표현식 기반 언어이기 때문에, 이것은 이해해야 할 중요한 구별입니다. 다른 언어들은 동일한 구별을 가지고 있지 않으므로, 어떤 문장과 표현식이 무엇인지, 그리고 그 차이점이 함수의 본문에 어떤 영향을 미치는지 살펴 보겠습니다.

  • 명령문은 몇 가지 작업을 수행하고 값을 반환하지 않는 명령입니다.
  • 표현식은 결과값으로 평가됩니다.

몇 가지 예를 살펴보자.

실제로 이미 구문과 표현식을 사용했습니다. 변수를 만들고 let 키워드로 값을 할당하는 것은 문입니다. Listing 3-1에서 let y = 6;는 문입니다.

함수 정의도 구문입니다. 앞의 예제 전체는 구문 자체입니다. (곧 살펴보겠지만, 함수를 호출하는 것은 구문이 아닙니다.)

문은 값을 반환하지 않습니다. 따라서 다음 코드가 시도하기 때문에 let 문을 다른 변수에 할당 할 수 없습니다. 오류가 발생합니다.

파일 이름: src/main.rs

fn main() {
    let x = (let y = 6);
}

파일 이름: src/main.rs

}

반환 값이 있는 함수

함수는 함수를 호출하는 코드에 값을 반환할 수 있습니다. 우리는 반환 값의 이름을 지정하지 않지만, 화살표 뒤에 그 타입을 선언해야 합니다 (->). 러스트에서, 함수의 반환 값은 함수의 본문 블록에 있는 최종 표현식의 값과 동의어입니다. return 키워드를 사용하여 함수에서 일찍 반환하고 값을 지정해야 하지만, 대부분의 함수는 암시적 값을 반환합니다.

파일 이름: src/main.rs

fn five() -> i32 {
    5
}

fn main() {
    let x = five();

    println!("The value of x is: {x}");
}

함수 호출, 매크로 또는 심지어 let 본문에서 In the five 기능 - 단지 숫자 5 그 자체로. 이것은 러스트에서 완벽하게 유효한 함수입니다. 함수의 반환 타입도 다음과 같이 지정됩니다. -> i32. 이 코드를 실행해보세요; 출력은 다음과 같아야 합니다:

$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.30s
     Running `target/debug/functions`
The value of x is: 5

이름 * 5 에서 five 함수의 반환 값이기 때문에 반환 형식은 다음과 같습니다. i32. 좀 더 자세히 살펴 보겠습니다. 두 가지 중요한 비트가 있습니다. 첫째, 선 let x = five(); 변수를 초기화하기 위해 함수의 반환 값을 사용하고 있음을 보여줍니다. 함수가 five 반환 A 5이 줄은 다음과 같습니다.This line is the same as the following:

#![allow(unused)]
fn main() {
let x = 5;
}

둘째, five 함수에는 매개 변수가 없으며 반환 값의 유형을 정의하지만 함수의 몸체는 세미콜론이없는 외로운 5입니다.

다른 예를 살펴보자:

}

fn plus_one(x: i32) -> i32 {
    x + 1
}
