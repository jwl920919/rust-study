The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

데이터 형식

러스트의 모든 값은 특정 데이터 유형입니다. 러스트는 어떤 종류의 데이터가 지정되고 있는지 알려 주어 해당 데이터로 작업하는 방법을 알고 있습니다. 스칼라와 컴파운드의 두 가지 데이터 유형 하위 집합을 살펴보겠습니다.

러스트 는 a 라는 것을 명심하세요. 정적으로 입력됨 언어, 이는 컴파일 시간에 모든 변수의 유형을 알고 있어야 함을 의미합니다. 컴파일러는 일반적으로 값을 기반으로하고 사용하는 방법을 사용하여 어떤 유형을 추론 할 수 있습니다. 우리가 변환 할 때와 같이 많은 유형이 가능한 경우 String 사용하는 숫자 형식입니다. parse 다음에서 “비밀 번호 에 대한 추측 을 비교 함” 무시 2 장의 섹션에서는 다음과 같은 형식 주석을 추가해야합니다.

스칼라 형식

스칼라 타입은 하나의 값을 나타냅니다. 러스트는 네 가지 기본 스칼라 타입을 가집니다: 정수, 부동 소수점 숫자, 부울 문자. 다른 프로그래밍 언어에서 이것을 인식할 수 있습니다. 러스트에서 어떻게 동작하는지 살펴봅시다.

정수 오버플로우

여러분이 타입의 변수가 있다고 가정해 봅시다. u8 0에서 255 사이의 값을 저장할 수 있습니다. 변수를 256과 같이 범위 외부의 값으로 변경하려고하면 정수 오버플로우 두 가지 동작 중 하나가 발생할 수 있습니다. 디버그 모드에서 컴파일할 때, 러스트는 여러분의 프로그램을 실행시키는 정수 오버플로우를 검사합니다. 패닉 이 동작이 실행될 때. 러스트는 이 용어를 사용합니다 패닉 프로그램이 오류와 함께 종료 될 때; 우리는 더 깊이에서 공황을 논의 할 것 이다 "복구 할 수없는 오류 panic!” 무시 chapter 9에서 발췌

--release 플래그로 릴리스 모드에서 컴파일 할 때, 러스트는 패닉을 일으키는 정수 오버플로 검사를 포함하지 않습니다. 대신, 오버플로우가 발생하면, 러스트는 두 개의 complement wrapping을 수행합니다. 간단히 말해서, 타입이 "wrap around"할 수 있는 최대값보다 큰 값은 타입이 가질 수 있는 최소값에 해당합니다. u8의 경우, 256 값은 0이 되고, 값은 0이 됩니다.

오버플로우의 가능성을 명시적으로 처리하려면, 기본 숫자형에 대해 표준 라이브러리에서 제공하는 이러한 메서드 패밀리를 사용할 수 있습니다.

  • 모든 편집 모드의 래핑 wrapping_* methods, 예를 들면 wrapping_add.
  • 반환값 None 상기 오버플로우하는 단계는 Wherein overflow with the checked_* 메서드.
  • overflowing_* 메서드가 오버플로우되었는지 여부를 나타내는 값과 부울을 반환합니다.
  • saturating_* 메서드를 사용하여 값의 최소 또는 최대 값으로 포화합니다.

부동 소수점 형식

러스트는 또한 소수점을 가진 숫자인 부동 소수점 숫자에 대한 두 가지 기본 유형을 가지고 있습니다. 러스트의 부동 소수점 유형은 f32 및 f64이며, 크기는 각각 32비트와 64비트입니다. 기본 유형은 f64입니다. 왜냐하면 현대 CPU에서는 f32와 거의 같은 속도이지만 더 정밀하게 부동할 수 있기 때문입니다.

다음은 부동 소수점 숫자가 동작하는 예제입니다.Here's an example that shows floating-point numbers in action:

파일 이름: src/main.rs

fn main() {
    let x = 2.0; // f64

    let y: f32 = 3.0; // f32
}

부동 소수점 숫자는 IEEE-754 표준에 따라 표시됩니다.

숫자 작업

러스트는 덧셈, 뺄셈, 곱셈, 나 ⁇ 셈, 나머지와 같은 모든 숫자 타입에 대해 기대하는 기본적인 수학적 연산을 지원합니다. 정수 분할은 가장 가까운 정수를 0으로 줄입니다. 다음 코드는 let 문에서 각 숫자 연산을 사용하는 방법을 보여줍니다:

파일 이름: src/main.rs

fn main() {
    // addition
    let sum = 5 + 10;

    // subtraction
    let difference = 95.5 - 4.3;

    // multiplication
    let product = 4 * 30;

    // division
    let quotient = 56.7 / 32.2;
    let truncated = -5 / 3; // Results in -1

    // remainder
    let remainder = 43 % 5;
}

이 문장의 각 표현식은 수학 연산자를 사용하고 하나의 값으로 평가되며 변수에 바인딩됩니다. 부록 B는 러스트가 제공하는 모든 연산자의 목록을 포함합니다.

부울 형식은

대부분의 다른 프로그래밍 언어에서와 마찬가지로, 러스트의 Boolean 타입은 두 가지 값을 가집니다: true와 false. Boolean은 1바이트 크기입니다. 러스트의 Boolean 타입은 bool를 사용하여 지정됩니다. 예:

파일 이름: src/main.rs

fn main() {
    let t = true;

    let f: bool = false; // with explicit type annotation
}

부울 값을 사용하는 주요 방법은 if 표현식과 같은 조건문을 사용하는 것입니다. if 표현식이 “통제 의 흐름” 섹션에서 러스트에서 어떻게 작동하는지 다룰 것입니다.

러스트의 char 타입은 언어의 가장 원시적인 알파벳 타입입니다. char 값을 선언하는 몇 가지 예는 다음과 같습니다:

파일 이름: src/main.rs

fn main() {
    let c = 'z';
    let z: char = 'ℤ'; // with explicit type annotation
    let heart_eyed_cat = '😻';

컴파운드 타입

컴파운드 타입은 여러 값을 하나의 타입으로 묶을 수 있습니다. 러스트는 두 가지 기본 컴파운드 타입을 가지고 있습니다: 튜플과 배열입니다.

튜플 타입은

튜플은 다양한 유형의 값을 하나의 화합물 유형으로 함께 그룹화하는 일반적인 방법입니다. 튜플의 길이는 고정되어 있습니다. 일단 선언되면 크기가 커지거나 축소될 수 없습니다.

우리는 괄호 안에 쉼표로 구분된 값 목록을 작성하여 튜플을 만듭니다. 튜플의 각 위치에는 유형이 있으며 튜플의 다른 값의 유형이 같을 필요는 없습니다. 이 예제에서 선택적 유형 주석을 추가했습니다.

파일 이름: src/main.rs

fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);
}

tup 변수는 튜플이 단일 화합물 요소로 간주되기 때문에 전체 튜플에 바인딩됩니다. 튜플에서 개별 값을 가져오려면 패턴 매칭을 사용하여 튜플 값을 분해할 수 있습니다.

파일 이름: src/main.rs

fn main() {
    let tup = (500, 6.4, 1);

    let (x, y, z) = tup;

    println!("The value of y is: {y}");
}

이 프로그램은 먼저 튜플을 만들고 변수에 바인딩합니다. tup. 다음과 같은 패턴을 사용합니다. let 받는 사람 tup 세 개의 변수로 나눠서, x, y, 그리고 z. 이것은 불린다 비정형 그것은 3개 부품으로 단 하나 튜플을 끊기 때문에. 마지막으로, 프로그램은 가치를의 인쇄합니다 y는, which 는 6.4.

우리는 또한 우리가 접근하고 싶은 가치의 색인에 선행된 기간 (.)를 이용하여 tuple 성분에 직접 접근할 수 있습니다. 예를 들면:

파일 이름: src/main.rs

fn main() {
    let x: (i32, f64, u8) = (500, 6.4, 1);

    let five_hundred = x.0;

    let six_point_four = x.1;

    let one = x.2;
}

이 프로그램은 튜플 x를 생성하고 각각의 인덱스를 사용하여 튜플의 각 요소에 액세스합니다. 대부분의 프로그래밍 언어와 마찬가지로 튜플의 첫 번째 인덱스는 0입니다.

어떤 값도 없는 튜플은 특별한 이름인 unit을 가지고 있습니다. 이 값과 그에 대응하는 타입은 둘 다 ()로 쓰여지고 빈 값이나 빈 반환 타입을 나타냅니다. 표현식은 다른 값을 반환하지 않으면 암시적으로 unit 값을 반환합니다.

Array 타입

여러 값의 컬렉션을 갖는 또 다른 방법은 배열을 사용하는 것입니다. 튜플과는 달리, 배열의 모든 요소는 같은 타입을 가져야 합니다. 다른 언어의 배열과는 달리, 러스트의 배열은 고정된 길이를 가집니다.

배열의 값을 쉼표로 구분된 목록으로 대괄호 안에 씁니다.

파일 이름: src/main.rs

fn main() {
    let a = [1, 2, 3, 4, 5];
}

배열은 스택에 할당된 데이터를 원할 때 유용하며, 힙이 아닌 지금까지 본 다른 유형과 동일합니다(스택과 힙에 대해 더 자세히 설명하겠습니다). 제 4 장 무시 ) 또는 항상 고정 된 수의 요소가 있는지 확인하고 싶을 때. 배열은 벡터 유형만큼 유연하지 않습니다. 벡터는 표준 라이브러리에서 제공하는 유사한 컬렉션 유형입니다. 있습니다. 내용이 힙에 있으므로 크기가 커지거나 작아질 수 있습니다. 배열이나 벡터를 사용할지 확실하지 않은 경우 벡터를 사용해야 합니다. 제 8 장 무시 벡터에 대해 더 자세히 설명합니다.

그러나 배열은 요소의 수를 변경할 필요가 없다는 것을 알고있을 때 더 유용합니다. 예를 들어 프로그램에서 월 이름을 사용하는 경우 항상 12 개의 요소가 포함되어 있다는 것을 알고 있기 때문에 벡터가 아닌 배열을 사용할 것입니다.

#![allow(unused)]
fn main() {
let months = ["January", "February", "March", "April", "May", "June", "July",
              "August", "September", "October", "November", "December"];
}

각 요소의 유형, 세미콜론 및 배열의 요소 수와 함께 대괄호를 사용하여 배열의 유형을 작성합니다.You write an array's type using square brackets with the type of each element, a semicolon, and then the number of elements in the array.

#![allow(unused)]
fn main() {
let a: [i32; 5] = [1, 2, 3, 4, 5];
}

여기서 i32는 각 요소의 유형입니다. 세미콜론 후 5는 배열에 5개의 요소가 포함되어 있음을 나타냅니다.

또한 배열을 초기화하여 초기 값을 지정하고 세미콜론 다음에 대괄호로 배열의 길이를 지정하여 각 요소에 대해 동일한 값을 포함할 수 있습니다.

#![allow(unused)]
fn main() {
let a = [3; 5];
}

a라는 배열에는 5 요소가 포함되어 처음에는 3 값으로 설정됩니다. 이것은 let a = [3, 3, 3, 3, 3];를 쓰는 것과 동일하지만 더 간결한 방법입니다.

배열 요소 액세스

배열은 스택에 할당할 수 있는 알려진 고정된 크기의 메모리 덩어리입니다. 배열의 요소에는 다음과 같이 인덱싱을 사용하여 액세스할 수 있습니다.

파일 이름: src/main.rs

fn main() {
    let a = [1, 2, 3, 4, 5];

    let first = a[0];
    let second = a[1];
}

이 예제에서 first라는 변수는 배열의 1 인덱스 값이므로 [0] 값을 가져옵니다. second라는 변수는 배열의 2 인덱스에서 [1] 값을 가져옵니다.

잘못된 배열 요소 접근

배열의 끝을 지나는 배열의 요소에 액세스하려고하면 어떻게되는지 봅시다. 이 코드를 2 장의 추측 게임과 유사하게 실행하여 사용자로부터 배열 인덱스를 얻는다고 가정 해 봅시다.

파일 이름: src/main.rs

use std::io;

fn main() {
    let a = [1, 2, 3, 4, 5];

    println!("Please enter an array index.");

    let mut index = String::new();

    io::stdin()
        .read_line(&mut index)
        .expect("Failed to read line");

    let index: usize = index
        .trim()
        .parse()
        .expect("Index entered was not a number");

    let element = a[index];

    println!("The value of the element at index {index} is: {element}");
}

이 코드는 성공적으로 컴파일됩니다. 이 코드를 실행하면 cargo run 들어가며 0, 1, 2, 3, 또는 4, 프로그램은 배열에 있는 저 색인에 대응 가치를 밖으로 인쇄할 것이다. 대신 배열의 끝을 지나서 수를 입력하는 경우에, 10다음과 같은 출력이 표시됩니다.You will see output like this:

thread 'main' panicked at src/main.rs:19:19:
index out of bounds: the len is 5 but the index is 10
note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

인덱싱 작업에서 유효하지 않은 값을 사용할 때 런타임 오류가 발생했습니다. 이 프로그램은 오류 메시지와 함께 종료되었으며 최종 println! 문을 실행하지 않았습니다. 인덱싱을 사용하여 요소에 액세스하려고 하면, 러스트는 지정한 인덱스가 배열 길이보다 작은지 확인합니다. 인덱스가 길이보다 크거나 같으면 러스트는 패닉에 빠질 것입니다. 이 검사는 런타임에서 발생할 수 있으므로 런타임에 실행할 수 있습니다.

이것은 실행 중인 러스트의 메모리 안전 원칙의 예입니다. 많은 저수준 언어에서 이러한 종류의 검사는 수행되지 않으며, 잘못된 인덱스를 제공하면 유효하지 않은 메모리에 접근할 수 있습니다. 러스트는 메모리 접근과 계속을 허용하는 대신 즉시 종료함으로써 이러한 종류의 오류로부터 사용자를 보호합니다. 9장은 러스트의 오류 처리에 대해 더 자세히 설명하고, 어떻게 여러분이 읽기 쉽고 안전한 코드를 작성할 수 있는지에 대해 설명합니다.
