# 러스트 프로그래밍 언어 — 한국어 번역 초안

최신 공식 Rust Book의 한국어 HTML 번역 초안입니다. `index.html`을 열면 책을 읽을 수 있으며, GitHub Pages의 저장소 루트 페이지로도 사용할 수 있습니다.

## 기준과 상태

- 기준 원문: Rust 1.97.0 및 Rust 2024 Edition
- 구성: 21개 장과 부록 전체, mdBook 기반 HTML
- 번역 상태: 기계 번역 초안이며 사람의 교정은 거치지 않았습니다. 기술 용어와 문장에 오역이 있을 수 있습니다.
- Rust 예제 코드는 공식 원문을 보존했습니다. 실행에는 인터넷 연결이 필요하며 공식 Rust Playground를 사용합니다.

## 로컬에서 읽기

`index.html`을 브라우저에서 열고 **책 시작**을 누릅니다. 모든 책 페이지와 정적 자산은 `book/` 아래에 있습니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 배포 원본을 `main` 브랜치의 `/ (root)`로 설정하면 루트 `index.html`을 진입점으로 사용할 수 있습니다.

## 출처와 라이선스

원본 책은 Rust 프로젝트의 저작물이며 MIT 또는 Apache-2.0 라이선스로 배포됩니다. 이 배포본에는 MIT 라이선스 전문과 필수 고지를 포함했습니다. 원문 링크, 번역 모델의 라이선스와 저작자 표기는 [ATTRIBUTION.md](ATTRIBUTION.md)를 참고하세요. 글꼴과 기타 타사 자산의 라이선스 파일은 `book/fonts/`에 보존했습니다.

이 저장소는 Rust 프로젝트의 공식 번역이나 공식 배포물이 아닙니다.
