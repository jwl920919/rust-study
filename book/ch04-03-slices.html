슬라이스 타입

슬라이스를 사용하면 모음집에서 연속된 요소를 참조할 수 있습니다. 슬라이스는 일종의 참조이므로 소유권이 없습니다.

다음은 작은 프로그래밍 문제입니다. 공백으로 구분 된 단어의 문자열을 가져 와서 해당 문자열에서 찾은 첫 번째 단어를 반환하는 함수를 작성하십시오. 함수가 문자열에서 공백을 찾지 못하면 전체 문자열이 한 단어 여야합니다. 따라서 전체 문자열을 반환해야합니다.

참고: 슬라이스 도입을 위해 이 섹션에서만 ASCII를 가정합니다. UTF-8 처리에 대한 자세한 설명은 8장의 "UTF-8 인코딩 된 텍스트를 문자열로 저장" 섹션에 나와 있습니다.

슬라이스를 사용하지 않고이 함수의 서명을 작성하는 방법을 통해 슬라이스가 해결할 문제를 이해합시다.

String 요소를 요소별로 살펴보고 값이 공백인지 확인해야 하므로 String 메서드를 사용하여 as_bytes를 바이트 배열로 변환합니다.

지금 연락

문자열 조각은 String의 요소의 연속적인 시퀀스에 대한 참조이며 다음과 같습니다.

fn main() {
    let s = String::from("hello world");

    let hello = &s[0..5];
    let world = &s[6..11];
}

전체를 언급하기 보다는 String, hello 상기 일부에 대한 참조는 The reference for a portion of the Stringin the extra ~에 지정된 [0..5] bit. 괄호 안에 슬라이스를 지정하여 슬라이스를 만듭니다. [starting_index..ending_index], 어디서 starting_index 상기 제 1 위치는 The first position and ending_index 슬라이스의 마지막 위치보다 하나 더 많습니다. 내부적으로 슬라이스 데이터 구조는 슬라이스의 시작 위치와 길이를 저장합니다. ending_index 빼기 starting_index. 그래서, 의 경우 let world = &s[6..11];, world 의 인덱스 6에서 바이트에 대한 포인터를 포함하는 슬라이스가 될 s length 값을 갖는 5.

그림 4-7은 이것을 그림으로 보여줍니다.

그림 4-7: String의 일부를 나타내는 문자열 슬라이스

러스트의 .. 범위 구문을 사용하면 인덱스 0에서 시작하려는 경우 두 기간 전에 값을 삭제할 수 있습니다. 즉, 다음과 같습니다.

#![allow(unused)]
fn main() {
let s = String::from("hello");

let slice = &s[0..2];
let slice = &s[..2];
}

동일한 토큰으로, 슬라이스에 String의 마지막 바이트가 포함되어 있는 경우, 후행 번호를 삭제할 수 있습니다. 즉, 다음과 같습니다.

#![allow(unused)]
fn main() {
let s = String::from("hello");

let len = s.len();

let slice = &s[3..len];
let slice = &s[3..];
}

또한 두 값을 모두 삭제하여 전체 문자열의 일부를 취할 수 있습니다.

#![allow(unused)]
fn main() {
let s = String::from("hello");

let len = s.len();

let slice = &s[0..len];
let slice = &s[..];
}

다른 슬라이스

스트링 슬라이스(string slice)는, 여러분이 상상하시겠지만, 스트링에 특유합니다. 하지만 더 일반적인 슬라이스 타입도 있습니다. 이 배열을 생각해 보세요:

#![allow(unused)]
fn main() {
let a = [1, 2, 3, 4, 5];
}

문자열의 일부를 참조하려는 것처럼 배열의 일부를 참조할 수 있습니다. 이렇게 하면 됩니다.

#![allow(unused)]
fn main() {
let a = [1, 2, 3, 4, 5];

let slice = &a[1..3];

assert_eq!(slice, &[2, 3]);
}

이 슬라이스에는 &[i32] 유형이 있습니다. 첫 번째 요소와 길이에 대한 참조를 저장하여 문자열 슬라이스와 같은 방식으로 작동합니다. 모든 종류의 다른 컬렉션에 이러한 종류의 슬라이스를 사용합니다. 8 장에서 벡터에 대해 이야기 할 때 이러한 컬렉션에 대해 자세히 설명합니다.

요약

소유권, 차용, 슬라이스의 개념은 러스트 프로그램에서 컴파일 시간에 메모리 안전을 보장합니다. 러스트 언어는 다른 시스템 프로그래밍 언어와 같은 방식으로 메모리 사용을 제어할 수 있습니다. 그러나 소유자가 범위를 벗어날 때 데이터 소유자가 자동으로 해당 데이터를 정리한다는 것은 이러한 제어를 얻기 위해 추가 코드를 작성하고 디버그할 필요가 없다는 것을 의미합니다.

소유권은 러스트의 다른 많은 부분에 영향을 미치므로, 이 책의 나머지 부분에서 이러한 개념에 대해 더 자세히 이야기하겠습니다. 5장으로 넘어가서 struct에서 함께 데이터 조각을 그룹화하는 것을 살펴봅시다.
