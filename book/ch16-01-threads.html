The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

스레드를 사용하여 코드를 동시에 실행

대부분의 현재 운영 체제에서 실행 된 프로그램의 코드는 프로세스에서 실행되며 운영 체제는 한 번에 여러 프로세스를 관리합니다. 프로그램 내에서 동시에 실행되는 독립적 인 부분을 가질 수도 있습니다. 이러한 독립적 인 부분을 실행하는 기능을 스레드라고합니다. 예를 들어 웹 서버에는 여러 개의 스레드가있어 동시에 하나 이상의 요청에 응답 할 수 있습니다.

여러 작업을 동시에 실행하기 위해 프로그램에서 계산을 여러 스레드로 분할하면 성능을 향상시킬 수 있지만 복잡성도 더할 수 있습니다. 스레드가 동시에 실행될 수 있기 때문에 다른 스레드에서 코드의 일부가 실행되는 순서에 대한 고유한 보장은 없습니다. 이로 인해 다음과 같은 문제가 발생할 수 있습니다.

  • 스레드가 일치하지 않는 순서로 데이터 또는 리소스에 액세스하는 레이스 조건
  • 두 개의 스레드가 서로를 기다리고있는 데드락으로 두 스레드가 계속되지 않습니다.
  • 특정 상황에서만 발생하고 안정적으로 재현하고 수정하기가 어려운 버그

러스트는 스레드 사용의 부정적인 영향을 완화하려고 시도하지만, 다중 스레드 컨텍스트에서의 프로그래밍은 여전히 신중한 생각을 필요로하며 단일 스레드에서 실행되는 프로그램에서와 다른 코드 구조가 필요합니다.

프로그래밍 언어는 스레드를 몇 가지 다른 방식으로 구현하며, 많은 운영 체제는 프로그래밍 언어가 새 스레드를 만들 때 호출할 수 있는 API를 제공합니다. 러스트 표준 라이브러리는 스레드 구현의 1:1 모델을 사용합니다. 따라서 프로그램은 하나의 언어 스레드 당 하나의 운영 체제 스레드를 사용합니다. 1:1 모델에 다른 트레이드 오프를 만드는 다른 스레드 모델을 구현하는 크레이트가 있습니다. (러스트의 비동기 시스템은 다음 장에서 볼 수 있듯이 동시성에 대한 또 다른 접근 방식을 제공합니다).
