추측 처리하기

추측 게임 프로그램의 첫 번째 부분은 사용자 입력을 요청하고, 그 입력을 처리하고, 입력이 예상 된 형식인지 확인합니다. 시작하려면 플레이어가 추측을 입력 할 수 있습니다. Listing 2-1의 코드를 src/main.rs에 입력하십시오.

이 코드에는 많은 정보가 포함되어 있으므로 한 줄씩 살펴 보겠습니다. 사용자 입력을 얻고 결과를 출력으로 인쇄하려면 io 입력 / 출력 라이브러리를 범위로 가져와야합니다. io 라이브러리는 std로 알려진 표준 라이브러리에서 제공됩니다.

use std::io;

fn main() {
    println!("Guess the number!");

    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    println!("You guessed: {guess}");
}

기본적으로, 러스트는 표준 라이브러리에 정의된 항목의 집합을 모든 프로그램의 범위로 가져옵니다. 이 집합을 프렐류드이라고 하며, 표준 라이브러리 문서에서 모든 항목을 볼 수 있습니다.

사용하려는 유형이 프렐류드에 없는 경우 use 문을 사용하여 명시적으로 해당 유형을 범위로 가져와야 합니다. std::io 라이브러리를 사용하면 사용자 입력을 수락하는 기능을 포함하여 여러 가지 유용한 기능을 제공합니다.

사용자 입력 받기

표준 라이브러리의 입력/출력 기능을 다음과 같이 포함시켰음을 상기하십시오. use std::io; 프로그램의 첫 번째 줄에 있습니다. 이제 우리는 stdin 에서 기능 io 사용자 입력을 처리할 수 있는 모듈:

use std::io;

fn main() {
    println!("Guess the number!");

    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    println!("You guessed: {guess}");

만약 import 하지 않았다면 io 모듈명 with use std::io; 프로그램의 시작 부분에서, 우리는 여전히이 함수 호출을 작성 하 여 기능을 사용할 수 있습니다. std::io::stdin. 그 stdin instance를 반환하는 함수 std::io::Stdin 무시 터미널의 표준 입력에 대한 핸들을 나타내는 형식입니다.

잠재적 실패에 대처하는 법 Result

우리는 여전히이 코드 라인에서 작업하고 있습니다. 이제 세 번째 텍스트 라인을 논의하고 있지만 여전히 단일 논리적 코드 라인의 일부라는 점에 유의하십시오. 다음 부분은이 방법입니다.

use std::io;

fn main() {
    println!("Guess the number!");

    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    println!("You guessed: {guess}");
}

이 코드를 다음과 같이 작성할 수 있습니다:

io::stdin().read_line(&mut guess).expect("Failed to read line");

그러나 한 줄은 읽기가 어렵기 때문에 나누는 것이 가장 좋습니다. .method_name() 구문을 사용하여 메서드를 호출 할 때 긴 줄을 나누기 위해 새 줄과 다른 공백을 소개하는 것이 좋습니다. 이제이 줄이 무엇인지 논의 해 봅시다.

앞에서 언급했듯이 read_line는 사용자가 입력하는 모든 문자열을 입력하지만 Result 값도 반환합니다. Result는 종종 enum이라고하는 열거이며 여러 가지 가능한 상태 중 하나에있을 수있는 유형입니다. 우리는 각 가능한 상태를 변형이라고 부릅니다.

제 6 장는 열거형을 더 자세히 다룰 것입니다. 이러한 Result 유형의 목적은 오류 처리 정보를 인코딩하는 것입니다.

Result의 변형은 Ok 및 Err입니다. Ok 변형은 작업이 성공했음을 나타내며 성공적으로 생성 된 값을 포함합니다. Err 변형은 작업이 실패했음을 의미하며 작업이 어떻게 또는 왜 실패했는지에 대한 정보가 포함되어 있습니다.

의 값 Result type은, 어떤 type의 값과 마찬가지로, 그에 정의된 메서드를 가지고 있습니다. Result 있습니다. expect 메서드 무시 당신이 호출할 수 있습니다. 이 인스턴스의 경우 Result 있습니다. Err 값, expect 프로그램이 충돌하고 인수로 전달 된 메시지를 표시하게됩니다. expect. 만약 read_line 메서드를 반환합니다. Err, 그것은 가능성이 기본 운영 체제에서 오는 오류의 결과 일 것이다. 이 인스턴스의 경우 Result 있습니다. Ok 값, expect 상기 반환되는 값은 The return value is Ok 이 값을 보유하고 반환하므로 사용할 수 있습니다. 이 경우 해당 값은 사용자 입력의 바이트 수입니다.

와 인쇄 값 println! 위치 지정자

closing curly bracket을 제외하고, 지금까지 코드에서 논의해야 할 라인이 하나 더 있습니다.

use std::io;

fn main() {
    println!("Guess the number!");

    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

이 줄은 사용자의 입력이 들어 있는 문자열을 출력합니다. {} 중괄호 집합은 자리 표시자입니다.Think of curly brackets is a placeholder. {} 변수의 값을 출력할 때 변수 이름은 중괄호 안으로 들어갈 수 있습니다. 식을 평가한 결과를 출력할 때 빈 중괄호를 형식 문자열에 넣은 다음 쉼표로 구분된 식 목록을 사용하여 형식 문자열을 따라 같은 순서로 각 중괄호 자리 표시자에 인쇄합니다. 한 번의 호출로 변수와 식의 결과를 출력하여 println! 그것은 이렇게 보일 것이다:

#![allow(unused)]
fn main() {
let x = 5;
let y = 10;

println!("x = {x} and y + 2 = {}", y + 2);
}

이 코드는 x = 5 and y + 2 = 12를 인쇄합니다.
