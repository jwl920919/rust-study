The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

설치

첫 번째 단계는 러스트를 설치하는 것입니다. 러스트 버전 및 관련 도구를 관리하기위한 명령줄 도구 인 rustup를 통해 러스트를 다운로드합니다. 다운로드하려면 인터넷 연결이 필요합니다.

참고 : 어떤 이유로 rustup를 사용하지 않으려는 경우 더 많은 옵션을 보려면 기타 러스트 설치 방법 페이지를 참조하십시오.

다음 단계는 러스트 컴파일러의 최신 안정 버전을 설치합니다. 러스트의 안정성은 컴파일되는 책의 모든 예제가 최신 러스트 버전으로 계속 컴파일되도록 보장합니다. 러스트는 종종 오류 메시지와 경고를 개선하기 때문에 출력은 버전마다 약간 다를 수 있습니다. 즉, 이 단계들을 사용하여 설치하는 최신의 안정적인 버전의 러스트는 이 책의 내용과 함께 예상대로 작동해야 합니다.

명령줄 표기

이 장과 책 전체에서 터미널에서 사용되는 몇 가지 명령을 보여줍니다. 터미널에 입력해야하는 줄은 모두 다음과 같습니다. $. 당신은을 입력 할 필요가 없습니다 $ character; 각 명령의 시작을 나타내는 명령줄 프롬프트입니다. 로 시작하지 않는 줄 $ 일반적으로 이전 명령의 출력을 표시합니다. 또한 PowerShell 특정 예제는 > 보다는 $.

설치 중 rustup Linux 또는 macOS에서

Linux 또는 macOS를 사용하는 경우 터미널을 열고 다음 명령을 입력합니다.

$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

이 명령은 스크립트를 다운로드하고 최신 안정 버전의 러스트를 설치하는 rustup 도구 설치를 시작합니다. 암호에 대한 메시지가 표시될 수 있습니다. 설치가 성공하면 다음 줄이 나타납니다.

Rust is installed now. Great!

또한 러스트가 컴파일된 출력을 하나의 파일로 결합하기 위해 사용하는 프로그램인 링커가 필요합니다. 이미 가지고 있을 가능성이 높습니다. 링커 오류가 발생하면 일반적으로 링커를 포함하는 C 컴파일러를 설치해야 합니다. 일부 일반적인 러스트 패키지는 C 코드에 의존하며 C 컴파일러가 필요하기 때문에 C 컴파일러도 유용합니다.

macOS에서는 다음을 실행하여 C 컴파일러를 얻을 수 있습니다.

$ xcode-select --install

Linux 사용자는 배포 설명서에 따라 일반적으로 GCC 또는 Clang을 설치해야합니다. 예를 들어, Ubuntu를 사용하는 경우 build-essential 패키지를 설치할 수 있습니다.

설치 중 rustup 윈도우에서

Windows에서 https://www.rust-lang.org/tools/install(으)로 돌아가기로 이동하여 러스트 설치 지침을 따르십시오. 설치 중 어느 시점에서는 Visual Studio를 설치하라는 메시지가 표시됩니다. 이렇게 하면 링커와 프로그램을 컴파일하는 데 필요한 기본 라이브러리가 제공됩니다. 이 단계에 대한 더 많은 도움이 필요하면 https://rust-lang.github.io/rustup/installation/windows-msvc.html에서 다운로드 할 수 있습니다.를 참조하십시오.

이 책의 나머지 부분은 cmd.exe와 PowerShell에서 모두 작동하는 명령을 사용합니다. 구체적인 차이점이 있다면 어떤 것을 사용할지 설명하겠습니다.

문제 해결

러스트가 올바르게 설치되었는지 확인하려면 쉘을 열고 다음 줄을 입력하십시오:

$ rustc --version

릴리스된 최신 안정 버전의 버전 번호, 커밋 해시 및 커밋 날짜가 다음 형식으로 표시됩니다.

rustc x.y.z (abcabcabc yyyy-mm-dd)

이 정보가 보이면 러스트를 성공적으로 설치했습니다! 이 정보가 보이지 않으면 다음과 같이 러스트가 %PATH% 시스템 변수에 있는지 확인하십시오.

Windows CMD에서는 다음을 사용합니다.

> echo %PATH%

PowerShell에서 다음을 사용합니다.

> echo $env:Path

Linux 및 macOS에서 다음을 사용하십시오.

$ echo $PATH

러스트가 여전히 작동하지 않는다면, 도움을 받을 수 있는 많은 장소가 있습니다. 커뮤니티 페이지에서 다른 러스트aceans (우리 자신을 부르는 바보 같은 별명)와 연락하는 방법을 알아보세요.

업데이트 및 제거

러스트가 rustup를 통해 설치되면, 새로 출시된 버전으로 쉽게 업데이트할 수 있습니다. 쉘에서 다음 업데이트 스크립트를 실행하세요:

$ rustup update

러스트 및 rustup를 제거하려면 쉘에서 다음 제거 스크립트를 실행하십시오.

$ rustup self uninstall

로컬 문서 읽기

러스트 설치에는 오프라인에서 읽을 수 있도록 문서의 로컬 복사본도 포함되어 있습니다. rustup doc를 실행하여 브라우저에서 로컬 문서를 엽니다.

어떤 타입이나 함수가 표준 라이브러리에 의해 제공되고 그것이 무엇을 하는지 또는 어떻게 사용하는지 확신할 수 없을 때마다, 알아내기 위해 API(application programming interface) 문서를 사용하라!

텍스트 편집기 및 IDE 사용

이 책은 러스트 코드를 작성하는 데 사용하는 도구에 대해 가정하지 않습니다. 모든 텍스트 편집기가 작업을 완료합니다! 그러나 많은 텍스트 편집기와 통합 개발 환경 (IDE)에는 러스트에 대한 지원이 내장되어 있습니다. 러스트 웹 사이트에서 Tools 페이지에서 많은 편집자와 IDE의 최신 목록을 항상 찾을 수 있습니다.

이 책으로 오프라인 작업하기

몇 가지 예에서 표준 라이브러리를 넘어서는 러스트 패키지를 사용할 것입니다. 이러한 예제를 수행하려면 인터넷 연결이 필요하거나 사전에 해당 종속성을 다운로드해야합니다. 종속성을 미리 다운로드하려면 다음 명령을 실행할 수 있습니다. (cargo가 무엇인지 그리고 각 명령이 나중에 자세히 설명 할 것입니다.)

$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.10.1 trpl@0.2.0

나중에 다운로드할 필요가 없도록 이 패키지에 대한 다운로드를 캐시합니다. 이 명령을 실행하면 get-dependencies 폴더를 유지할 필요가 없습니다. 이 명령을 실행한 경우 --offline 플래그를 모든 cargo 명령과 함께 사용할 수 있습니다.
