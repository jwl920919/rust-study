The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

변수 및 가변성

변수가 있는 값Storing Values with Variables 섹션에서 언급했듯이, 기본적으로 변수는 불변입니다. 이것은 러스트가 제공하는 안전하고 쉬운 동시성을 이용하는 방식으로 코드를 작성하도록 하는 많은 넛지 중 하나입니다. 그러나, 당신은 여전히 변수를 변경할 수 있는 옵션이 있습니다. 어떻게 그리고 왜 러스트가 당신이 불변성을 선호하도록 격려하는지, 그리고 왜 때때로 당신이 옵트 아웃하기를 원하는지를 탐구해 봅시다.

변수가 불변인 경우 값이 이름에 바인딩되면 해당 값을 변경할 수 없습니다. 이를 설명하기 위해 cargo new variables를 사용하여 프로젝트 디렉토리에 변수라는 새 프로젝트를 생성합니다.

그런 다음 새 변수 디렉토리에서 src/main.rs를 열고 코드를 아직 컴파일되지 않은 다음 코드로 바꿉니다.

파일 이름: src/main.rs

fn main() {
    let x = 5;
    println!("The value of x is: {x}");
    x = 6;
    println!("The value of x is: {x}");
}

cargo run를 사용하여 프로그램을 저장하고 실행하십시오. 이 출력과 같이 불변 오류에 관한 오류 메시지가 나타납니다.

오류 메시지를 받았습니다 cannot assign twice to immutable variable `x` 왜냐하면 당신은 불변의 값에 두 번째 값을 할당하려고했기 때문입니다. x 변수.

변경 불가능으로 지정된 값을 변경하려고 할 때 컴파일 타임 오류를 발생시키는 것이 중요합니다. 이 상황은 버그로 이어질 수 있기 때문입니다. 우리 코드의 한 부분이 값이 변하지 않고 다른 부분이 그 값을 변경한다는 가정 하에 작동한다면, 코드의 첫 번째 부분은 원래 의도했던 대로 작동하지 않을 수 있습니다. 이런 종류의 버그의 원인은 특히 두 번째 코드의 변경 후에만 추적하기가 어려울 수 있습니다.

그러나 가변성은 매우 유용하고 코드를 작성하는 것이 더 편리 할 수 있습니다. 변수는 기본적으로 변경할 수 없지만 mut에서했던 것처럼 변수 이름 앞에 제 2 장를 추가하여 변경할 수 있습니다. mut를 추가하면 코드의 다른 부분이이 변수의 값을 변경한다는 것을 나타내어 미래의 코드 독자에게 의도를 전달할 수 있습니다.

예를 들어, src/main.rs 를 다음과 같이 변경해보자:

파일 이름: src/main.rs

fn main() {
    let mut x = 5;
    println!("The value of x is: {x}");
    x = 6;
    println!("The value of x is: {x}");
}

The value of x is: 5
The value of x is: 6

상수 선언하기

불변 변수와 마찬가지로 상수는 이름에 바인딩된 값이며 변경할 수 없지만 상수와 변수 간에는 몇 가지 차이점이 있습니다.

첫째, 사용할 수 없습니다. mut constants를 사용합니다. Constants는 기본적으로 불변일 뿐만 아니라 항상 불변입니다. const 키워드 대신 let keyword, 그리고 값의 타입 필수 주석을 달겠습니다. 다음 섹션에서는 타입과 타입 주석을 다룰 것입니다. “데이터 유형” 무시 , 그래서 지금 세부 사항에 대해 걱정하지 마십시오. 항상 유형에 주석을 추가해야한다는 것을 알고 있습니다.

상수는 전역 범위를 포함하여 모든 범위에서 선언될 수 있으며, 이는 코드의 많은 부분이 알아야 하는 값에 유용합니다.

마지막 차이점은 상수가 런타임에 계산될 수 있는 값의 결과가 아닌 상수 표현식으로만 설정될 수 있다는 것입니다.

다음은 상수 선언의 예입니다.Here's an example of a constant declaration:

#![allow(unused)]
fn main() {
const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;
}

상수의 이름은 다음과 같습니다. THREE_HOURS_IN_SECONDS, 그리고 그 값은 60 (분당 초 수)에 60 (시간당 분 수)을 3 (이 프로그램에서 계산하려는 시간 수)으로 곱한 결과로 설정됩니다. 상수에 대한 러스트의 명명 규칙은 단어 사이에 밑줄이있는 모든 대문자를 사용하는 것입니다. 컴파일러는 컴파일 시간에 제한된 작업 집합을 평가할 수 있으므로이 값을보다 쉽게 작성할 수 있으며이 값을보다 쉽게 확인할 수 있습니다. 지속적인 평가에 관한 러스트 Reference의 섹션 상수를 선언할 때 사용할 수 있는 작업에 대한 자세한 정보.

상수는 프로그램이 실행되는 전체 시간 동안 선언된 범위 내에서 유효합니다. 이 속성은 프로그램의 여러 부분이 알아야 할 응용 프로그램 도메인의 값에 유용한 상수를 만듭니다(예: 게임의 모든 플레이어가 얻을 수 있는 최대 포인트 수 또는 빛의 속도).

프로그램 전체에서 사용되는 하드코딩된 값을 상수로 명명하는 것은 미래의 코드 관리자에게 해당 값의 의미를 전달하는 데 유용합니다. 또한 나중에 하드코딩된 값을 업데이트해야 하는 경우 변경해야 하는 코드에서 한 곳만 갖는 것도 도움이 됩니다.

섀도잉

당신이 추측 게임 튜토리얼에서 본대로 제 2 장 무시 , 이전 변수와 같은 이름의 새로운 변수를 선언할 수 있습니다. 러스트aceans는 첫 번째 변수가 그림자 두 번째 변수는 두 번째 변수가 변수의 이름을 사용할 때 컴파일러가 볼 수 있음을 의미합니다. 실제로 두 번째 변수는 첫 번째 변수를 덮어 쓰고 변수 이름이 쉐도우되거나 스코프가 끝날 때까지 변수 이름을 자체적으로 사용합니다. 우리는 같은 변수의 이름을 사용하고 같은 변수를 반복하여 변수를 그림자로 만들 수 있습니다. let 다음과 같이 키워드:

파일 이름: src/main.rs

fn main() {
    let x = 5;

    let x = x + 1;

    {
        let x = x * 2;
        println!("The value of x in the inner scope is: {x}");
    }

    println!("The value of x is: {x}");
}

이 프로그램은 먼저 바인딩합니다. x 값에 대한 To a value 5. 그런 다음 새 변수를 만듭니다. x 반복하여 let x =, 원래 값을 복용하고 추가 1 상기 값은 The value of x 있습니다. 6. 그런 다음, 중괄호로 만든 내부 범위 내에서 세 번째 let 그림자 Shadows x 새로운 변수를 만들고, 이전 값을 다음과 같이 곱합니다. 2 기부하다 x a 값 12. 그 범위가 끝날 때, 안 shadowing는 끝납니다 x 존재로 되돌아가다 6. 이 프로그램을 실행하면 다음과 같이 출력됩니다.

Shadowing은 변수를 mut로 표시하는 것과는 다릅니다. let 키워드를 사용하지 않고 실수로 이 변수에 재할당을 시도하면 컴파일 타임 오류가 발생합니다. let를 사용하면 값에 대한 몇 가지 변환을 수행 할 수 있지만 변환이 완료된 후에는 변수를 변경할 수 없습니다.

mut와 섀도잉의 또 다른 차이점은 let 키워드를 다시 사용할 때 새로운 변수를 효과적으로 만들기 때문에 값의 유형을 변경하고 동일한 이름을 재사용 할 수 있다는 것입니다. 예를 들어, 프로그램에서 사용자에게 스페이스 문자를 입력하여 텍스트 사이에 몇 개의 공백을 표시하도록 요청한 다음 해당 입력을 숫자로 저장하려고 한다고 가정해 보겠습니다.

fn main() {
    let spaces = "   ";
    let spaces = spaces.len();
}

첫 번째 spaces 변수는 문자열 형식이고 두 번째 형식입니다. spaces 변수는 숫자 유형입니다. 따라서 Shadowing은 다음과 같은 다른 이름을 만들어 낼 필요가 없습니다. spaces_str 그리고 spaces_num대신, 우리는 더 간단한 것을 재사용 할 수 있습니다. spaces 이름. 그러나, 우리가 사용하려고하면 mut 이것을 위해, 여기에서 보이는 것처럼, 우리는 컴파일 타임 오류를 얻을 것이다:

fn main() {
    let mut spaces = "   ";
    spaces = spaces.len();
}

이 오류는 변수의 타입을 변경하는 것이 허용되지 않는다고 말합니다:
