리터럴 일치

6장에서 보듯이, 리터럴과 패턴을 직접 매치할 수 있습니다. 다음 코드는 몇 가지 예제를 제공합니다.

fn main() {
    let x = 1;

    match x {
        1 => println!("one"),
        2 => println!("two"),
        3 => println!("three"),
        _ => println!("anything"),
    }
}

이 코드는 one를 인쇄합니다. x의 값이 1이기 때문입니다. 이 구문은 특정 구체적인 값을 얻는 경우 코드를 실행하려는 경우에 유용합니다.

다중 패턴 매칭

match 표현식에서 패턴 또는 연산자 인 | 구문을 사용하여 여러 패턴을 일치시킬 수 있습니다. 예를 들어 다음 코드에서 x의 값을 일치 암과 일치시킵니다. 첫 번째 암에는 옵션이나 옵션이 있습니다. 즉, x의 값이 해당 암의 값 중 하나와 일치하는 경우 해당 암이 실행됩니다.

fn main() {
    let x = 1;

    match x {
        1 | 2 => println!("one or two"),
        3 => println!("three"),
        _ => println!("anything"),
    }
}

이 코드는 one or two를 인쇄합니다.

값의 범위와 일치 ..=

..= 구문을 사용하면 포괄적 인 범위의 값과 일치시킬 수 있습니다. 다음 코드에서 패턴이 주어진 범위 내의 값과 일치하면 해당 팔이 실행됩니다.

fn main() {
    let x = 5;

    match x {
        1..=5 => println!("one through five"),
        _ => println!("something else"),
    }
}

있는 경우 x 있습니다. 1, 2, 3, 4, 또는 5, 첫 번째 암이 일치합니다. 이 구문은 다음을 사용하는 것보다 여러 일치 값에 더 편리합니다. | 같은 생각을 표현하는 연산자; 우리가 사용하는 경우 |# 명시해야 할 사항 1 | 2 | 3 | 4 | 5범위를 지정하는 것은 훨씬 더 짧은데, 특히 1과 1,000 사이의 숫자를 일치시키고 싶다면 더욱 그렇습니다!

컴파일러는 컴파일 시간에 범위가 비어있지 않은지 확인하고, 범위가 비어있는지 아닌지를 알 수 있는 유일한 타입이 char이고 숫자 값이기 때문에, 범위는 숫자 또는 char 값에서만 허용됩니다.

다음은 char 값의 범위를 사용하는 예입니다.

fn main() {
    let x = 'c';

    match x {
        'a'..='j' => println!("early ASCII letter"),
        'k'..='z' => println!("late ASCII letter"),
        _ => println!("something else"),
    }
}

러스트는 'c'가 첫 번째 패턴의 범위 내에 있으며 early ASCII letter를 인쇄한다는 것을 알 수 있습니다.

구조체와 튜플

우리는 훨씬 더 복잡한 방법으로 비구조화 패턴을 혼합, 일치 및 중첩 할 수 있습니다. 다음 예는 튜플 안에 구조체와 튜플을 중첩하고 모든 원시 값을 비구조화하는 복잡한 구조를 보여줍니다.

fn main() {

        x: i32,

사용 @ 바인딩

이름 * 위치 운영자 @ 패턴 일치에 대한 값을 테스트하는 동시에 값을 가지는 변수를 만들 수 있습니다. Listing 19-29에서, 우리는 Message::Hello id 범위 내에 있는 필드 3..=7우리는 또한 값을 변수에 바인딩하고 싶습니다. id 그래서 우리는 팔과 관련된 코드에서 그것을 사용할 수 있습니다.

이 예제에서는 Found an id in range: 5를 인쇄합니다. 범위 id @ 앞에 3..=7를 지정하면 변수 id의 범위와 일치하는 값을 캡처하는 동시에 값이 범위 패턴과 일치하는지 테스트합니다.

패턴에 지정된 범위만 있는 두 번째 arm에는 arm과 관련된 코드에 실제 값이 포함된 변수가 없습니다. id 필드. The id 필드의 값은 10, 11 또는 12 일 수 있지만 해당 패턴과 함께 제공되는 코드는 해당 패턴을 알지 못합니다. 패턴 코드는 해당 패턴의 값을 사용할 수 없습니다. id 왜냐하면 우리가 구하지 않았기 때문입니다. id 변수에 있는 값입니다.

마지막 arm에서는 범위가 없는 변수를 지정했는데, arm의 코드에서 id라는 변수에서 사용할 수 있는 값을 가지고 있습니다. 그 이유는 struct field shorthand 구문을 사용했기 때문입니다. 하지만 처음 두 arm에서 했던 것처럼 이 arm의 id 필드의 값에 테스트를 적용하지 않았습니다. 모든 값은 이 패턴과 일치합니다.

@를 사용하면 값을 테스트하고 한 패턴 내의 변수에 저장할 수 있습니다.

요약

러스트의 패턴은 서로 다른 종류의 데이터를 구별하는 데 매우 유용합니다. match 표현식에 사용될 때, 러스트는 여러분의 패턴이 가능한 모든 값을 다루거나 여러분의 프로그램이 컴파일되지 않도록 합니다. let 문과 함수 파라미터의 패턴은 이러한 구조를 더 유용하게 만들어, 값을 더 작은 부분으로 분해하고 이러한 부분을 변수에 할당합니다. 우리는 우리의 필요에 맞게 간단하거나 복잡한 패턴을 만들 수 있습니다.

다음으로, 이 책의 마지막 장을 위해, 우리는 러스트의 다양한 특징들의 몇 가지 고급 측면들을 살펴볼 것입니다.
