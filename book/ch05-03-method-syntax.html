러스트는 -> 연산자와 동등한 기능을 가지고 있지 않습니다. 대신, 러스트는 자동 참조 및 역참조라는 기능을 가지고 있습니다. 호출 메서드는 러스트에서 이러한 동작을 수행하는 몇 안되는 장소 중 하나입니다.

작동 방식은 다음과 같습니다. object.something()를 사용하여 메서드를 호출하면 러스트는 자동으로 &, &mut 또는 *를 추가하여 object가 메서드의 서명과 일치하도록 합니다. 즉, 다음과 같습니다.

#![allow(unused)]
fn main() {
#[derive(Debug,Copy,Clone)]
struct Point {
    x: f64,
    y: f64,
}

impl Point {
   fn distance(&self, other: &Point) -> f64 {
       let x_squared = f64::powi(other.x - self.x, 2);
       let y_squared = f64::powi(other.y - self.y, 2);

       f64::sqrt(x_squared + y_squared)
   }
}
let p1 = Point { x: 0.0, y: 0.0 };
let p2 = Point { x: 5.0, y: 6.5 };
p1.distance(&p2);
(&p1).distance(&p2);
}

첫 번째는 훨씬 깔끔해 보입니다. 이 자동 참조 동작은 메서드가 self의 유형인 명확한 수신기를 가지고 있기 때문에 작동합니다. 메서드의 수신기와 이름을 감안할 때, 러스트는 메서드가 읽기(&self), 뮤팅(&mut self) 또는 소비(self)인지를 확실히 알아낼 수 있습니다.

요약

Structs를 사용하면 도메인에 의미 있는 사용자 지정 형식을 만들 수 있습니다. structs를 사용하면 연결된 데이터 조각을 서로 연결하고 각 조각의 이름을 지정하여 코드를 명확하게 할 수 있습니다. impl 블록에서 유형과 관련된 함수를 정의할 수 있으며, 메서드는 구조체의 인스턴스가 갖는 동작을 지정할 수 있는 연관 함수의 일종입니다.

그러나 structs가 사용자 지정 유형을 만들 수 있는 유일한 방법은 아닙니다: 도구 상자에 다른 도구를 추가하기 위해 러스트의 열거형 기능으로 돌아가 봅시다.
