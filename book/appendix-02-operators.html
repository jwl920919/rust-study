The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

부록 B: 연산자와 기호

이 부록에는 Rust의 문법 용어집이 포함되어 있습니다. 여기에는 경로, 제네릭, 트레이트 바운드, 매크로, 속성, 주석, 튜플, 괄호의 문맥에서 단독으로 나타나는 연산자와 기타 기호가 포함되어 있습니다.

연산자

표 B-1에는 Rust의 연산자, 해당 연산자가 문맥에서 어떻게 나타나는지 보여주는 예시, 간단한 설명, 그리고 해당 연산자가 오버로드 가능한지 여부가 포함되어 있습니다. 연산자가 오버로드 가능한 경우, 해당 연산자를 오버로드하는 데 사용할 관련 트레이트가 나열됩니다.

기호설명
