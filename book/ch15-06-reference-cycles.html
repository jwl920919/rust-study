파일 이름: src/main.rs

use std::cell::RefCell;
use std::rc::{Rc, Weak};

#[derive(Debug)]
struct Node {
    value: i32,
    parent: RefCell<Weak<Node>>,
    children: RefCell<Vec<Rc<Node>>>,
}

fn main() {
    let leaf = Rc::new(Node {
        value: 3,
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![]),
    });

    println!("leaf parent = {:?}", leaf.parent.borrow().upgrade());

    let branch = Rc::new(Node {
        value: 5,
        parent: RefCell::new(Weak::new()),
        children: RefCell::new(vec![Rc::clone(&leaf)]),
    });

    *leaf.parent.borrow_mut() = Rc::downgrade(&branch);

    println!("leaf parent = {:?}", leaf.parent.borrow().upgrade());
}

카운트와 값 드롭을 관리하는 모든 논리가 내장되어 있습니다. Rc<T> 그리고 Weak<T> 그리고 그들의 실행은, Drop 특성. 자식에서 부모로의 관계가 a가 되어야 한다고 지정함으로써 Weak<T> 의 정의에 참조 Node부모 노드가 자식 노드를 가리키도록 할 수 있으며, 참조 주기와 메모리 누수를 생성하지 않고도 그 반대의 경우도 마찬가지입니다.

요약

이 장에서는 스마트 포인터를 사용하여 러스트와 다른 보증과 트레이드 오프를 만드는 방법을 다루었습니다. Box<T> type은 힙에 할당된 데이터에 대해 알려진 크기와 포인트를 가지고 있습니다. Rc<T> type은 힙의 데이터에 대한 참조 수를 추적하여 데이터가 여러 소유자를 가질 수 있도록 합니다. RefCell<T> 그것의 내부 가변성을 가진 유형은 우리가 불변 유형을 필요로 할 때 우리가 이용할 수 있고 그러나 그 유형의 내부 가치를 바꿀 필요가 있는 유형을 준다; 그것은 또한 컴파일 시간에 런타임에 차입 규칙을 강제한다.

또한 스마트 포인터의 많은 기능을 가능하게하는 Deref 및 Drop 특성에 대해 논의했습니다. 메모리 누수를 유발할 수있는 참조주기와 Weak<T>를 사용하는 방법을 모색했습니다.

이 장이 당신의 관심사를 자극 하 고 당신이 당신의 자신의 똑똑한 포인터를 실행 하 고 싶은 경우에, 더 유용한 정보를 위해 러스토노미콘(The 러스트onomicon)를 체크아웃 하십시오.
