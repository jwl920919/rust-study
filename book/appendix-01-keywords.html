The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

부록 A: 키워드

다음 목록은 Rust 언어에서 현재 사용하거나 앞으로 사용할 목적으로 예약한 키워드입니다. 따라서 식별자로 사용할 수 없습니다(“원시 식별자” 절에서 설명하는 원시 식별자는 예외입니다). 식별자는 함수, 변수, 매개변수, 구조체 필드, 모듈, 크레이트, 상수, 매크로, 정적 변수, 속성, 타입, 트레이트, 라이프타임의 이름입니다.

현재 사용 중인 키워드

다음은 현재 사용 중인 키워드 목록이며, 각 키워드의 기능을 설명합니다.

  • as: 원시 타입 캐스팅을 수행하거나, 항목이 포함된 특정 트레이트를 명확히 지정하거나, use 문에서 항목 이름을 변경합니다.
  • async: 현재 스레드를 차단하는 대신 Future를 반환합니다.
  • await: Future의 결과가 준비될 때까지 실행을 일시 중단합니다.
  • break: 루프를 즉시 종료합니다.
  • const: 상수 항목 또는 상수 원시 포인터를 정의합니다.
  • continue: 다음 루프 반복으로 진행합니다.
  • crate: 모듈 경로에서 크레이트 루트를 가리킵니다.
  • dyn: 트레이트 객체에 대한 동적 디스패치.
  • else: if 및 if let 제어 흐름 구조의 폴백 역할을 합니다.
  • enum: 열거형을 정의합니다.
  • extern: 외부 함수 또는 변수를 링크합니다.
  • false: 부울 거짓 리터럴.
  • fn: 함수 또는 함수 포인터 타입을 정의합니다.
  • for: 반복자의 항목을 순회하거나, 트레이트를 구현하거나, 고위 랭킹 라이프타임을 지정합니다.
  • if: 조건 표현식의 결과에 따라 분기합니다.
  • impl: 고유 메서드 또는 트레이트 기능을 구현합니다.
  • in: for 루프 구문의 일부입니다.
  • let: 변수를 바인딩합니다.
  • loop: 조건 없이 반복합니다.
  • match: 값을 패턴과 매칭합니다.
  • mod: 모듈을 정의합니다.
  • move: 클로저가 모든 캡처의 소유권을 가져가도록 합니다.
  • mut: 참조, 원시 포인터, 또는 패턴 바인딩에서 가변성을 나타냅니다.
  • pub: 구조체 필드, impl 블록, 또는 모듈에서 공개 가시성을 나타냅니다.
  • ref: 참조로 바인딩합니다.
  • return: 함수에서 반환합니다.
  • Self: 정의하거나 구현하는 타입에 대한 타입 별칭입니다.
  • self: 메서드의 수신자 또는 현재 모듈입니다.
  • static: 프로그램 실행 전체 기간 동안 유지되는 전역 변수 또는 라이프타임입니다.
  • struct: 구조체를 정의합니다.
  • super: 현재 모듈의 상위 모듈입니다.
  • trait: 트레이트를 정의합니다.
  • true: 부울 true 리터럴입니다.
  • type: 타입 별칭 또는 연관 타입을 정의합니다.
  • union: 유니온을 정의합니다. union 선언에서 사용될 때만 키워드로 취급됩니다.
  • unsafe: 안전하지 않은 코드, 함수, 트레이트 또는 구현을 나타냅니다.
  • use: 심볼을 스코프에 가져옵니다.
  • where: 타입을 제약하는 절을 나타냅니다.
  • while: 식의 결과에 따라 조건부로 반복합니다.

미래에 사용할 목적으로 예약된 키워드

다음 키워드들은 아직 기능이 없지만, Rust에서 향후 사용을 위해 예약되어 있습니다:

  • abstract
  • become
  • box
  • do
  • final
  • gen
  • macro
  • override
  • priv
  • try
  • typeof
  • unsized
  • virtual
  • yield

원시 식별자

원시 식별자는 일반적으로 허용되지 않는 위치에 키워드를 사용할 수 있게 하는 구문입니다. 키워드 앞에 r#를 붙여 원시 식별자를 사용합니다.

예를 들어, match는 키워드입니다. match을 함수 이름으로 사용하는 다음 코드를 컴파일하려고 하면:

파일 이름: src/main.rs

fn match(needle: &str, haystack: &str) -> bool {
    haystack.contains(needle)
}

다음과 같은 오류가 발생합니다:

error: expected identifier, found keyword `match`
 --> src/main.rs:4:4
  |
4 | fn match(needle: &str, haystack: &str) -> bool {
  |    ^^^^^ expected identifier, found keyword

이 오류는 match 키워드를 함수 식별자로 사용할 수 없음을 보여줍니다. match를 함수 이름으로 사용하려면 다음과 같이 원시 식별자 구문을 사용해야 합니다.

파일 이름: src/main.rs

fn r#match(needle: &str, haystack: &str) -> bool {
    haystack.contains(needle)
}

fn main() {
    assert!(r#match("foo", "foobar"));
}

이 코드는 오류 없이 컴파일됩니다. 함수 정의 시 함수 이름에 붙은 r# 접두사와 main에서 함수가 호출되는 곳에 붙은 접두사에 주목하세요.

원시 식별자를 사용하면 예약 키워드인 경우를 제외하고, 원하는 어떤 단어를 식별자로 사용할 수 있습니다. 이를 통해 식별자 이름을 더 자유롭게 선택할 수 있으며, 해당 단어가 키워드가 아닌 다른 언어로 작성된 프로그램과도 통합할 수 있습니다. 또한 원시 식별자를 사용하면 현재 크레이트에서 사용하는 것과 다른 Rust 에디션으로 작성된 라이브러리를 사용할 수 있습니다. 예를 들어, try은 2015 에디션에서는 키워드가 아니지만 2018, 2021, 2024 에디션에서는 키워드로 사용됩니다. 2015 에디션으로 작성되어 try 함수를 가진 라이브러리에 의존하는 경우, 이후 에디션에서 해당 함수를 호출하려면 r#try과 같은 원시 식별자 구문을 사용해야 합니다. 에디션에 대한 자세한 내용은 부록 E를 참고하세요.
