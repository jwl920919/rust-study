## 이 책에서 다루는 내용

Rust 설치와 Cargo 사용법부터 소유권, 타입, 오류 처리, 동시성까지 순서대로 익힙니다. 마지막에는 스레드 풀을 사용하는 웹 서버를 만들어 봅니다.

- **1–2장 — 시작하기:** Rust 설치, Hello World, Cargo, 추측 게임
- **3–6장 — 언어 기초:** 변수와 타입, 함수와 제어 흐름, 소유권과 참조, 구조체, 열거형과 패턴 매칭
- **7–10장 — 프로젝트와 타입 시스템:** 패키지·크레이트·모듈, 컬렉션, 오류 처리, 제네릭·트레이트·라이프타임
- **11–14장 — 개발 흐름:** 테스트, 명령줄 프로그램, 반복자와 클로저, Cargo와 워크스페이스
- **15–17장 — 메모리와 동시성:** 스마트 포인터, 스레드와 공유 상태, async/await와 Future·Stream
- **18–20장 — 고급 언어 기능:** 객체 지향 설계, 패턴, unsafe Rust, 매크로와 기타 고급 기능
- **21장 — 최종 프로젝트:** 멀티스레드 웹 서버
- **부록 A–G:** 키워드, 연산자, 파생 트레이트, 개발 도구, 에디션, 번역본, Nightly Rust

## 페이지에서 Rust 코드 실험하기

책의 실행 가능한 Rust 예제 아래 **실험실에서 편집**을 누르면 예제 코드가 코드 실험실에 들어옵니다. 코드를 고치거나 새로 작성한 뒤 실행 결과를 확인할 수 있습니다.

- Rust 에디션 선택: 2015, 2018, 2021, 2024
- **실행** 버튼 또는 `Ctrl + Enter` (Mac: `Command + Enter`)로 실행
- **예제 코드로 되돌리기**로 마지막에 불러온 예제를 복원
- **공식 Playground에서 열기**로 Rust Playground에서 같은 코드를 확인

실행은 브라우저 안의 로컬 컴파일러가 아니라 공식 [Rust Playground](https://play.rust-lang.org/)에서 처리됩니다. **실행을 누르면 작성한 코드와 선택한 에디션이 인터넷을 통해 Playground로 전송됩니다.** 공식 Playground 링크를 누르면 코드가 URL에도 포함됩니다. 비밀번호, 토큰 등 공개하면 안 되는 값은 코드에 넣지 마세요. 실행에는 인터넷 연결이 필요합니다.
