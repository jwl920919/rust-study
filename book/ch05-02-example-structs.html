The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

구조체를 사용한 예제 프로그램

언제 구조체를 사용할지 이해하기 위해 사각형의 면적을 계산하는 프로그램을 작성해 봅시다. 우리는 단일 변수를 사용하여 시작하고 대신 구조체를 사용할 때까지 프로그램을 리팩터링 할 것입니다.

Cargo라는 새로운 바이너리 프로젝트를 픽셀로 지정된 직사각형의 너비와 높이를 취하고 직사각형의 면적을 계산합니다. Listing 5-8은 프로젝트의 src / main.rs에서 정확히 수행하는 한 가지 방법으로 짧은 프로그램을 보여줍니다.

이제 cargo run를 사용하여이 프로그램을 실행하십시오.

$ cargo run
   Compiling rectangles v0.1.0 (file:///projects/rectangles)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.42s
     Running `target/debug/rectangles`
The area of the rectangle is 1500 square pixels.

이 코드는 각 차원마다 area 함수를 호출하여 사각형의 영역을 알아내는 데 성공하지만이 코드를 명확하고 읽기 쉽게 만들기 위해 더 많은 작업을 수행 할 수 있습니다.

이 코드의 문제는 area의 서명에서 분명합니다.

fn main() {
    let width1 = 30;
    let height1 = 50;

    println!(
        "The area of the rectangle is {} square pixels.",
        area(width1, height1)
    );
}

fn area(width: u32, height: u32) -> u32 {
    width * height
}

area 함수는 한 직사각형의 면적을 계산해야하지만 작성한 함수에는 두 가지 매개 변수가 있으며 프로그램의 어느 곳에서도 매개 변수가 관련되어 있는지 명확하지 않습니다. 함께 너비와 높이를 그룹화하는 것이 더 읽기 쉽고 관리하기 쉽습니다. 우리는 이미 튜플을 사용하여 튜플 타입(The Tuple Type) 섹션에서 그렇게 할 수있는 한 가지 방법을 논의했습니다.

Debug 형식을 사용하여 값을 인쇄하는 또 다른 방법은 표현식의 소유권을 갖는 dbg! 매크로를 사용하는 것입니다(참조를 받는 println!와는 반대로), dbg! 매크로 호출이 코드에서 해당 표현식의 결과값과 함께 발생하고 값의 소유권을 반환하는 파일 및 라인 번호를 인쇄합니다.

이름: Calling dbg! 표준 오류 콘솔 스트림에 매크로 인쇄 (stderr(반대되는 경우 println!표준 출력 콘솔 스트림(Standard Output Console Stream)stdout). 우리는에 대해 더 이야기 할 것이다 stderr 그리고 stdout 다음에서 12 장의 "표준 오류로 오류 리디렉션"섹션 무시 .

다음은 width 필드에 할당되는 값과 rect1의 전체 구조체 값에 관심이 있는 예입니다.

#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

fn main() {
    let scale = 2;
    let rect1 = Rectangle {
        width: dbg!(30 * scale),
        height: 50,
    };

    dbg!(&rect1);
}

우리는 넣을 수 있습니다 dbg! 표현식의 주위에 30 * scale 그리고, 왜냐하면 dbg! 표현식의 값의 소유권을 반환한다. width 필드는 우리가 가지고 있지 않은 경우와 같은 값을 얻을 것이다. dbg! 전화하십시오. 우리는 원하지 않습니다. dbg! 소유권을 소유하기 위하여 rect1그래서, 우리는 참조를 사용합니다. rect1 다음 호출에서. 이 예제의 출력은 다음과 같습니다.
