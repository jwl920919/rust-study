The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

해시 맵에서 관련 값과 키 저장Storing Keys with Associated Values in Hash Maps

공통 컬렉션의 마지막은 해시 맵입니다. HashMap<K, V> 타입의 키의 맵핑 저장 K 타입의 값 V 사용 A 해싱 함수이러한 키와 값을 메모리에 배치하는 방법을 결정합니다. 많은 프로그래밍 언어는 이러한 종류의 데이터 구조를 지원하지만 종종 다음과 같은 다른 이름을 사용합니다. 해시, 지도, 객체, 해시 테이블, 사전, 또는 연관 배열그냥 몇 가지 이름을합니다.

해시 맵은 인덱스를 사용하지 않고 벡터로 할 수 있지만 모든 유형의 키가 될 수있는 키를 사용하여 데이터를 조회 할 때 유용합니다. 예를 들어 게임에서 각 키는 팀의 이름이고 값은 각 팀의 점수 인 해시 맵에서 각 팀의 점수를 추적 할 수 있습니다. 팀 이름을 감안할 때 점수를 검색 할 수 있습니다.

이 섹션에서는 해시 맵의 기본 API를 살펴 보겠습니다. 그러나 더 많은 것들이 표준 라이브러리에서 HashMap<K, V>에 정의된 함수에 숨어 있습니다. 항상 그렇듯이 표준 라이브러리 설명서에서 자세한 정보를 확인하십시오.

해시 맵에서 값에 액세스

여기, score 블루 팀과 관련된 값을 갖게되고 그 결과는 10. 그 get 메서드를 반환합니다. Option<&V>; 해시 맵에 그 키에 대한 값이 없다면, get 돌아올 것이다. None. 이 프로그램은 Option 전화 걸기 copied 을 얻기 위해 Option<i32> 대신 an Option<&i32>다음 것 unwrap_or 설정하기 score 0 0 만약 scores 열쇠에 대한 입구가 없습니다.

for 루프를 사용하여 벡터와 비슷한 방식으로 해시 맵에서 각 키-값 쌍을 반복할 수 있습니다.

fn main() {
    use std::collections::HashMap;

    let mut scores = HashMap::new();

    scores.insert(String::from("Blue"), 10);
    scores.insert(String::from("Yellow"), 50);

    for (key, value) in &scores {
        println!("{key}: {value}");
    }
}

이 코드는 각 쌍을 임의의 순서로 인쇄합니다:

Yellow: 50
Blue: 10

Hash Maps에서 소유권 관리

Copy 트레잇을 구현하는 타입의 경우, i32와 같은 값은 해시 맵에 복사됩니다. String와 같은 소유 값의 경우, 값이 이동되고 해시 맵은 Listing 8-22에서 설명한 것처럼 해당 값의 소유자가 됩니다.

우리는 변수를 사용할 수 없습니다. field_name 그리고 field_value 그들은에 호출과 함께 해시 맵으로 이동 한 후 insert.

해시 맵에 값에 대한 참조를 삽입하면 값은 해시 맵으로 이동되지 않습니다. 참조가 가리키는 값은 적어도 해시 맵이 유효한 한 유효해야합니다. 10 장의 “평생 참고할 만한 것 들”에서 이러한 문제에 대해 자세히 이야기 할 것입니다.

해시 맵 업데이트

키와 값 쌍의 수는 증가할 수 있지만, 각 고유 키는 한 번에 하나의 값만 가질 수 있습니다(예: Blue 팀과 Yellow 팀은 모두 10에 저장된 값을 scores 해시 맵에 가질 수 있음).

해시 맵에서 데이터를 변경하려면 키가 이미 할당 된 경우 사례를 처리하는 방법을 결정해야합니다. 이전 값을 새 값으로 대체하여 이전 값을 완전히 무시할 수 있습니다. 이전 값을 유지하고 새 값을 무시할 수 있습니다. 키가 이미 값이없는 경우에만 새 값을 추가합니다. 또는 이전 값과 새 값을 결합 할 수 있습니다. 각각을 수행하는 방법을 살펴 보겠습니다!

요약

벡터, 문자열 및 해시 맵은 데이터를 저장, 액세스 및 수정해야 할 때 프로그램에 필요한 많은 기능을 제공합니다. 이제 해결할 수있는 몇 가지 연습이 있습니다.

  1. 정수 목록이 주어지면, 벡터를 사용하고 목록의 중앙값(정렬될 때, 중간 위치의 값)과 모드(가장 자주 발생하는 값, 해시 맵이 도움이 될 것입니다)를 반환합니다.
  2. 문자열을 Pig Latin으로 변환하십시오. 각 단어의 첫 자음은 단어의 끝으로 이동하고 ay가 추가되므로 먼저 irst-fay가됩니다. 모음으로 시작하는 단어는 대신 끝에 추가되었습니다 (사과는 사과가됩니다). UTF-8 인코딩에 대한 세부 사항을 명심하십시오!
  3. 해시 맵과 벡터를 사용하여 사용자가 회사의 부서에 직원 이름을 추가 할 수 있도록 텍스트 인터페이스를 만듭니다. 예를 들어, "엔지니어링에 샐리 추가"또는 "판매에 Amir 추가". 그런 다음 사용자가 부서 또는 부서의 모든 사람 목록을 알파벳순으로 정렬합니다.
