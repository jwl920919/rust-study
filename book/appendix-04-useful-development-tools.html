The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

부록 D: 유용한 개발 도구

이 부록에서는 러스트 프로젝트가 제공하는 몇 가지 유용한 개발 도구에 대해 설명합니다. 자동 포맷팅, 경고 수정을 적용하는 빠른 방법, linter 및 IDE와의 통합을 살펴 보겠습니다.

자동 서식 지정 rustfmt

rustfmt 도구는 커뮤니티 코드 스타일에 따라 코드를 다시 포맷합니다. 많은 공동 프로젝트는 rustfmt를 사용하여 러스트를 작성할 때 사용할 스타일에 대한 인수를 방지합니다.

러스트 설치 포함 rustfmt 기본적으로, 그래서 당신은 이미 프로그램을 가지고 있어야 rustfmt 그리고 cargo-fmt 당신의 시스템에. 이 2개의 명령은 유사합니다 rustc 그리고 cargo 그 안에서 rustfmt 더 정밀한 곡물 통제를 허용하고 cargo-fmt Cargo를 사용하는 프로젝트의 규칙을 이해합니다. 모든 Cargo 프로젝트를 포맷하려면 다음을 입력하십시오.

$ cargo fmt

이 명령을 실행하면 현재 크레이트의 모든 러스트 코드를 다시 포맷합니다. 이것은 코드 스타일을 변경해야하며 코드 의미론을 변경해서는 안됩니다. rustfmt에 대한 자세한 내용은 #문서를 참조하십시오.

코드 수정 rustfix

rustfix 도구는 러스트 설치에 포함되어 있으며 원하는 문제를 해결할 수있는 명확한 방법이있는 컴파일러 경고를 자동으로 수정할 수 있습니다. 이전에 컴파일러 경고를 본 적이있을 것입니다. 예를 들어 다음 코드를 고려하십시오.

파일 이름: src/main.rs

fn main() {
    let mut x = 42;
    println!("{x}");
}

여기서는 x 변수를 가변 변수로 정의하고 있지만 실제로 변경하지는 않습니다. 러스트는 다음과 같이 경고합니다.

$ cargo build
   Compiling myprogram v0.1.0 (file:///projects/myprogram)
warning: variable does not need to be mutable
 --> src/main.rs:2:9
  |
2 |     let mut x = 0;
  |         ----^
  |         |
  |         help: remove this `mut`
  |
  = note: `#[warn(unused_mut)]` on by default

경고는 mut 키워드를 제거 할 것을 제안합니다. rustfix 명령을 실행하여 cargo fix 도구를 사용하여 해당 제안을 자동으로 적용 할 수 있습니다.

$ cargo fix
    Checking myprogram v0.1.0 (file:///projects/myprogram)
      Fixing src/main.rs (1 fix)
    Finished dev [unoptimized + debuginfo] target(s) in 0.59s

src/main.rs를 다시 보면 cargo fix가 코드를 변경했음을 알 수 있습니다.

파일 이름: src/main.rs

fn main() {
    let x = 42;
    println!("{x}");
}

x 변수는 이제 변경할 수 없으며 경고가 더 이상 나타나지 않습니다.

또한 cargo fix 명령을 사용하여 다른 러스트 에디션 간에 코드를 전환할 수 있습니다. 에디션은 부록 E에서 다룹니다.

클리피가 있는 더 많은 린트

Clippy 도구는 코드를 분석하여 일반적인 실수를 포착하고 러스트 코드를 향상시킬 수 있도록 lints 모음입니다. Clippy는 표준 러스트 설치에 포함되어 있습니다.

모든 Cargo 프로젝트에서 Clippy의 lint를 실행하려면 다음을 입력합니다.

$ cargo clippy

예를 들어, 이 프로그램과 같이 pi와 같은 수학적 상수의 근사치를 사용하는 프로그램을 작성한다고 가정해 보겠습니다.

이 프로젝트에서 cargo clippy를 실행하면 다음과 같은 오류가 발생합니다.

error: approximate value of `f{32, 64}::consts::PI` found
 --> src/main.rs:2:13
  |
2 |     let x = 3.1415;
  |             ^^^^^^
  |
  = note: `#[deny(clippy::approx_constant)]` on by default
  = help: consider using the constant directly
  = help: for further information visit https://rust-lang.github.io/rust-clippy/master/index.html#approx_constant

이 오류는 러스트가 이미 더 정확한 PI 상수를 정의하고 있으며, 대신 상수를 사용하면 프로그램이 더 정확할 것이라는 것을 알려줍니다. 그런 다음 PI 상수를 사용하도록 코드를 변경합니다.

IDE 통합 사용 rust-analyzer

IDE 통합을 돕기 위해, 러스트 커뮤니티는 rust-analyzer 무시 . 이 도구는 컴파일러 중심 유틸리티의 집합입니다 언어 서버 프로토콜 무시 , 서로 교통할 것이다 IDEs와 프로그램 언어를 위한 명세인. 다른 클라이언트는 사용할 수 있습니다 rust-analyzer예를 들어, Visual Studio 코드용 러스트 분석기 플러그인.

설치 지침은 rust-analyzer 프로젝트의 홈 페이지를 방문 한 다음 특정 IDE에 언어 서버 지원을 설치하십시오. IDE는 자동 완성, 정의로 이동 및 인라인 오류와 같은 기능을 제공합니다.
