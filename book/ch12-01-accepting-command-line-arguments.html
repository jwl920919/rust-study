The Rust Programming Language

한국어 기계 번역 초안입니다. Rust 코드와 인라인 코드 예제는 공식 최신 원문 그대로 보존했습니다. 번역 용어와 세부 문장은 계속 검토합니다.

명령행 인자를 받음

언제나처럼 cargo new를 사용하여 새 프로젝트를 만들어 보겠습니다. minigrep 프로젝트를 호출하여 이미 시스템에있을 수있는 grep 도구와 구별합니다.

$ cargo new minigrep
     Created binary (application) `minigrep` project
$ cd minigrep

첫 번째 작업은 minigrep가 두 개의 명령 행 인수를 수락하도록하는 것입니다. 파일 경로와 검색 할 문자열입니다. 즉, cargo run로 프로그램을 실행할 수 있기를 원합니다. 다음 인수를 나타내는 두 하이픈은 cargo, 검색 할 문자열 및 검색 할 파일의 경로입니다.

$ cargo run -- searchstring example-filename.txt

현재 cargo new에서 생성 된 프로그램은 우리가 제공하는 인수를 처리 할 수 없습니다. 크레이트.io의 일부 기존 라이브러리는 명령 줄 인수를 허용하는 프로그램을 작성하는 데 도움이 될 수 있지만이 개념을 배우고 있기 때문에이 기능을 직접 구현해 보겠습니다.

우리가 벡터를 인쇄 할 때 보았 듯이, 프로그램의 이름은 벡터의 첫 번째 값을 차지합니다. args[0], 그래서 우리는 인덱스 1에서 인수를 시작합니다. 첫 번째 인수 minigrep takes는 우리가 찾고 있는 문자열이므로 변수의 첫 번째 인수에 대한 참조를 넣습니다. query. 두 번째 인수는 파일 경로이므로 변수의 두 번째 인수를 참조합니다. file_path.

우리는 일시적으로 이러한 변수의 값을 인쇄하여 코드가 의도 한대로 작동 함을 증명합니다. test 및 sample.txt 인수를 사용하여이 프로그램을 다시 실행합시다.
